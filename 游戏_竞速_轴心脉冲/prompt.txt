轴心脉冲 AXELPULSE · 俯视环道漂移竞速：做一个"在非欧风场里解算矢量动力学、把可站立的路面本身当作会被压塌的耗材、并且只能在主动同调时才回补资源"的网页环道竞速游戏。单文件、整屏、深空仪表台风格，镜头固定俯视，环道是一条极坐标闭合曲线而不是恒定圆；画面由多块物理独立的画布分层承载（主视窗环道剖面 / 动态仪表组 / 环境雷达与远端预警 / 环形计量 / 收益倍率账本），玩法由多套互相环形耦合的物理、资源与空间判定子系统共同决定。images/ 下 8 张 1536×864 截图为同一个游戏在同一次会话内的 8 个状态，以图片为准；图上看不清或没有的数字与文案，不要臆造成确定事实。

世界与操作总览（八图共有，跨图不得漂移）：环道是一条极坐标闭合曲线 r(θ) = R₀ + A·cos(n·θ + φ)，弯道数 n 由难度决定，因此曲率沿 θ 逐点变化——既不是恒定圆，也不是直道折线，限速只能逐点解算。环道在横向上被切成五层环带，由内向外依次是**轴心环 / 内切线 / 中线带 / 外切线 / 真空带**，每一层有各自的**摩擦系数**与**风剪倍率**（这两组数在 img_003 的仪表组里整表列出，以图为准）；越靠外摩擦越低、风剪越强，走线选择因此是有代价的。环道沿 θ 被切成 24 段可站立浮屿，每段浮屿有独立的寿命、下沉位移与回弹速度；其中一部分浮屿正中带一段高亮窄带，那就是**锚定核心区**。环的正中是**轴心本体**，它有一格"轴心耦合余量"，只要还有拦截单位在航，这一格就按秒被侵蚀，归零即本局失败——所以清波不是加分项，是保命的必需动作。共有五类拦截单位：拦截机、穿刺艇、重装拦截（带甲壳，只有足够快的冲击波或同调脉冲才破得开）、相位体（穿身而过的行波，**不可拦截**，只能靠相位翻转规避）、以及第十波压上的轴心卫戍。共 10 波，数量、混编与血速倍率逐波抬升，第 10 波带轴心卫戍。正赛 10 圈，跑满即完赛；也可以在被耗尽之前把十波清空。三档难度（新手 / 标准 / 极限）在标题层选择，各自给出不同的弯道数、轴心初始余量、氮气储量，以及限速、敌速、风剪倍率、寿命衰减倍率——这四组数可从 img_001 的三张难度卡上直接读到，必须与图一致。

赛车的操纵面（八图共用同一套，键位提示常驻 img_003 仪表组左栏）：A / D 或左右方向键打舵，给的是**侧向速度**而不是位移；W 给切向油门，S 是刹车——**接触同调驻留必须刹停**，油门按着就永远压不进低速窗口。Space 是手刹漂移（把抓地回复速率降到另一档，滑移角可以撑得更大），J 是浮空跃迁，K 是**长按蓄能、松手弹射**，L 是空间相位翻转，U 是空域能量索，I 是浮屿共振主动同调脉冲。侧向不是一个可以瞬变的量：舵给的是目标侧速，抓地按一个回复速率把它拉过去，同时离心力按"曲率 × 速度平方"往外甩，三者同量级地拔河——所以打舵是"养成"而不是"设定"。

一、五个环形耦合子系统（≥5，必须环环相扣，禁止任何一个是独立的）

- **子系统 1 · 非欧微气象与动力学矢量解算核心**：风场不是一个常数，而是多层内波模态叠加出来的矢量场，振幅、角向波数、频率与相位逐模态不同；速度剪切使相邻半径处的风向局部反号，因此"顺风"与"逆风"在环道上交替出现，没有哪一段能一顺到底。赛车被所在环带的风剪平流带走，而**推进的有效出力随相对风向折减**：顺风时阻力被**非线性放大**（图上读数为"顺风 · 阻尼 ×1.40"），逆风时迎角反而产生一个**向上的升力矢量**（图上读数为"逆风 · 升力矢量"），也就是说顶着风跃迁反而更高更省。侧向机动必须借层间流向差"摆渡"。风切矢量罗盘必须实时给出模值与顺 / 逆 / 横三档判定。环道本身是极坐标闭合曲线，曲率带符号且逐点变化，离心外推因此逐段改变方向——限速不能靠"直道 / 弯道"两张表查。
- **子系统 2 · 多实体物理衰变与反作用力系统**：每一段浮屿都有独立的寿命、下沉位移与回弹速度。被载重时寿命按秒衰减，空载时按另一个速率重组回复。赛车落上去的瞬间，该段浮屿的下沉冲量**由其落地速度决定**，且关系是**超线性的**：轻落几乎不动，重落迅速逼近上限——具体形式为下沉冲量 = 基准 × (1 + 落地速度² / 除数)，其中基准与除数由实现方自选。**关键的反直觉点在于「载重」的判据**：载重取决于赛车当前所在的**格位**而不是脚底离地与否——原地跃迁、刹车压停都不算驶离；只有格位真的推进了，脚下那一段才算被抛下，此时它以**小于 1 的固定回弹系数**朝反方向弹起（反冲系数在图上未标注，由实现方选定，但必须小于 1 且方向与下沉相反），并点燃引信，引信逾期即碎裂为**不可站立**的虚空，一段时间后自行重组。若把载重判据写成"脚底离地"，低速起跳等于自己把脚下踩塌，落地必死，整局会卡在回溯循环里出不来。
- **子系统 3 · 主动式能量循环与过载熔断引擎**：氮气、稳定性储备与动能**绝对禁止自然被动恢复**——只要没有主动手段在施加，这三项随时间只能持平或下降，绝不能上升。氮气只有两个来源：落在**锚定浮屿正中的核心区**并完成一次驻留同调，或完成一次带足够切向速度的**能量索摆荡释放**。稳定性储备只在核心区内增长，而**停在浮屿边缘则按每秒固定比例持续流失**（速率可从 img_001 标题层与 img_003 仪表组的稳定性储备条标签读到）。结构疲劳只在长时间大滑移与撞击中累积，只有锚定同调期间才缓慢修复。**过载熔断**是这套循环的安全阀：蓄能量越过安全线并继续顶过满值即强制释放、扣分并进入一段硬直，且熔断有独立计数进入结算。这套循环必须真的闭合：同调 → 氮气 → 蓄能弹射与同调脉冲 → 击杀 → 轴心余量 → 危机分支 → 被迫熔断 → 硬直期间浮屿被压碎 → 可站立面变少 → 精准同调的点位变少 → 回到第一步。
- **子系统 4 · 多实体空间拓扑与分层判定系统**：每一段浮屿在几何上被切成三层——正中的**核心受击点**（锚定核心区，只占弧长的一小段，图上以高亮窄带画出）、两侧的**擦弹边缘**、以及下方的**动量吸收域**。三层的判定条件互不相同：站在核心带上才计入"精准落点"并回补氮气与稳定性；停在边缘上不但不计精准还要按秒扣稳定性；而动量吸收域决定速坠冲击的传播半径与衰减。判定因此是**分层**的：同一段浮屿，站在正中与停在两侧给出完全相反的资源结算。此外还有一条独立的空间判定：相位体是**不可拦截**的，撞上去必定失败，唯一的规避手段是空间相位翻转——翻转后的一段窗口内相位免疫，窗口外则照撞不误。速坠冲击的伤害与半径都由那一刻的下向速度决定，越过某个速度门才能击穿重装拦截的甲壳，否则只算一次无效碰撞。
- **子系统 5 · 逐帧事件溯源与结算审计账本**：每一件有意义的事都以（帧号、时刻、事件类型、带符号数额、人类可读说明）五元组记入账本，账本只增不删，界面上滚动显示最近若干条。结算面板上的每一个数字都必须由这本账**回溯聚合**得到，写死数值直接判零。账本同时是收益倍率的来源：连续事件累积连击段数，段数越高同一事件入账的额度越高，而连击有一段归零倒计时，长时间没有新事件即整段清零。轴心耦合余量的每一次侵蚀、每一次波次压上与击杀、每一次状态迁移与熔断、每一次回溯的原因，都必须能从账本里逐条追出来；而浮屿的引信与碎裂是**逐格连续显示的状态量**（走环形计量的格位状态与雷达栏的引信 / 虚空两个计数），**不逐格写进账本**——账本只收离散事件，否则同一段浮屿的反复进出会把整本账淹没。

环形闭环（必须真的闭环，不能只是并列）：风切矢量 → 侧向与垂向姿态 → 能否停在浮屿核心带 → 驻留同调 → 氮气与稳定性 → 能否完成蓄能弹射、能量索摆荡与同调脉冲 → 能否清掉在航拦截单位 → 轴心侵蚀速率 → 是否触发危机分支 → 是否被迫进入过载熔断 → 熔断硬直期间浮屿被压碎 → 可站立面变少 → 精准同调的点位变少 → 回到第一步。任何一环断开，整局都会退化成一个可以靠单一手段刷分的玩法。

至少 3 块物理独立的 `<canvas>` 节点，各自持有自己的绘制上下文，禁止把全部内容画进同一块全屏画布再靠裁切分区。基准版式下为 5 块：**A · 主视窗环道剖面**（整条闭合环道、五层环带分层着色、24 段浮屿与其寿命、锚定核心区高亮带、引信与虚空状态、轴心本体、拦截单位、赛车与其漂移痕、相位翻转的视差倾角扰动、危机暗角、熔断告警罩、回溯暗幕）、**B · 动态仪表组**（风切矢量罗盘 / 切向与侧向速度 / 滑移角 / 五层环带色标整表 / 氮气三段能量 / 稳定性储备 / 结构疲劳 / 蓄能压缩量含安全线与满值 / 实时损耗率监视器 / 当前环带与曲率与浮屿寿命 / 名次与反超与撞墙与回溯 / 常驻键位提示）、**C · 环境雷达与远端预警**（把环形赛道展开成一条直条，给出波次进度、外环剩余浮屿数与引信/虚空计数、威胁架数与交战状态、当前环带及其摩擦与风剪、圈次与上一圈用时）、**D · 环形计量**（24 格浮屿寿命环形条、同调充盈环、多段连击蓄能槽、当前收益倍率与连击归零倒计时、底部统计带）、**E · 收益倍率账本**（按帧号与时刻两条索引滚动的五元组事件流与总收益率）。

四、复合高阶交互手势（≥5 种微操作，全部必须真实可玩、有明确手感，且都消耗有限资源）

1. **动量下压速坠冲击**：按住下压键使赛车获得额外下向加速度并同时抽走氮气；触地瞬间按下坠速度生成冲击波（半径与伤害随速度变化），速度越过门槛才能击穿重装拦截的甲壳。
2. **非线性张力蓄能弹射**：长按蓄能、松手发射。冲量对蓄能量是**超线性**的（指数大于 1，越接近满值边际收益越大，且必须是非等比——把蓄能量减半，冲量必须掉到远低于一半），蓄能期间持续抽走氮气；蓄能越满，发射瞬间越需要留出垂向余量。
3. **空间相位瞬时翻转**：一次瞬时相位切换，代价是固定的一笔氮气与一段**以百毫秒计的视差倾角扰动窗口**（窗口内画面边缘出现撕裂描边并逐帧衰减），同时获得一段相位免疫。这是躲避不可拦截的相位体的唯一手段。
4. **空域能量索抓取与摆荡释放**：在抓取半径内抓住沿环道分布的锚塔，机身按**单摆方程**摆动（有阻尼），松手时按切向速度加权回补氮气——但只有切向速度越过下限才给气，且脱离角由玩家自选。这是氮气在远离核心区时的唯一补给途径，因此摆荡必须真的"荡起来"才有价值。
5. **浮屿共振主动同调释放**：在锚定核心区驻留满同调后释放一次脉冲，以固定半径造成伤害并可击穿重装拦截的甲壳；释放后进入一段冷却，冷却期间同调不可再蓄——**不允许靠连续点按刷取**。

另有基础操纵面（油门、刹车、转向、手刹漂移、浮空跃迁、暂停/重开/返回）不计入上述五种复合手势。

五、反常识机制（必须真实生效，照常识惯性实现必然失败）

1. **接触同调时延**：触地**不等于**同调。落点必须先把速度压到近零并连续保持满一段以百毫秒计的窗口（**350 ms**，写在 img_001 标题层里，以图为准），同调才开始推进；触地瞬间的"落地即给"是错的，在窗口内提前给油同样会把进度打回。"落地即蓄"意味着玩家可以在任意浮屿上无限刷资源，整局资源约束当场失效。跃迁余量同理：落地**不得**立刻回满，只有在驻留满窗口之后才由 0 置为 1。
2. **零被动恢复与静止消耗**：氮气、稳定性储备与动能**没有任何随时间自然回复的路径**。氮气只能来自核心区驻留或能量索摆荡释放；稳定性储备只在核心区增长，而**停在浮屿边缘则按每秒固定比例流失**（**5%/s**，写在 img_001 标题层里，以图为准）；动能越不动越少。因此"什么都不做地悬停"是纯亏损——若按"随时间慢慢回满"实现，整局资源约束会立刻失效。
3. **反常识风阻与下沉反冲力学**：顺风时阻力被**非线性放大 40%**（图上"顺风 · 阻尼 ×1.40"），因此**顺风反而更慢**；逆风时迎角产生一个**向上的升力矢量**，顶着风跃迁反而更高。浮屿的下沉冲量对落地速度**不是线性的**：轻落几乎不动，重落迅速逼近上限，形式为 `v_sink = 1.2 × (1 + v_impact² / 200)`——速度越大越接近饱和。浮屿被驶离的瞬间以**小于 1 的固定回弹系数 k = 0.68** 朝**反方向**弹起，此后经过 **500 ms** 引信碎裂为不可站立的虚空（引信时长写在 img_001 标题层与 img_003 环形计量的"离台挂 500 ms 引信"标注里，以图为准；回弹系数本身图上不打印，取值由实现方选定，但必须小于 1 且方向与下沉相反）。若按"平台静止不动"或"线性下沉"实现，速坠冲击的收益与风险关系会完全反过来。**注意载重判据**：载重取"当前格位"而非"脚底离地"，否则原地跃迁等于自己把脚下踩塌。

题面只给行为级、物理级的黑盒验收规范：不给出任何具体常数（重力加速度、跃迁初速、冲击伤害数值、各速率的每秒数值、结算权重与评级分档、碰撞检测的实现方式、伪随机数发生器的实现）——这些一律由实现方自行选定，但必须与上文描述的全部响应关系自洽。**例外有两类**：其一是第五节点名的三条反常识关系式与时延（它们是本题的判定核心，必须逐字生效）；其二是图上已经画出来的那些读数：凡是参考图里能直接读到或能由读数反推的数字（同调驻留毫秒数、引信毫秒数、边缘流失速率、顺风阻尼倍率、核心区高亮窄带占浮屿弧长的比例、各难度档的弯道数与轴心余量与氮气储量及四项倍率、五层环带的摩擦与风剪整表、蓄能安全线与满值、账本倍率等），一律以图为准并与图保持一致；图上读不到的，才由实现方自行选定。结算的各分量只需做到"逐帧可读、可由账本反推"，权重与分档不出题面。

八、验收

基准版式 1536×864；实测覆盖 1024、1152、1280、1366、1440、1600、1920、2560 八档宽度，均不得出现横向或纵向溢出，主视窗、状态徽标与全部仪表在这些宽度下都必须可见。基础可运行性四项缺一不可：文档可被语法解析且无未闭合标签；在 1280×720 下可成功启动；主视窗实际绘制出可检测的非白、非纯黑图形内容；从加载到交互的全生命周期内控制台不出现任何未捕获异常。物理必须以固定步长推进，仿真步进不得低于 60 Hz、不得随渲染帧率波动而改变；软件光栅化环境下持续运行 60 秒，渲染帧率在整个过程中不得持续劣化（末段窗口均值不得低于首段窗口均值的 85%），长时运行不得崩溃，首帧不得为白屏或黑屏。八张参考图必须两两可辨：任意两张在主视窗区域的像素差异都必须显著高于同一场景内的噪声底，不得靠机械裁切、局部放大、换色、镜像、滤镜或轻微位移伪造出新的状态帧。结算面板的全部数值必须来自当局实时账本的回溯聚合，写死数值直接判零。上文全部断言以最终成品的实测结果为唯一判据，不以上述说明本身为准。
