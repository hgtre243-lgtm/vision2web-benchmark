复现一幅矢量场景插画「潮汐灯塔 TIDAL BEACON」——夜潮海岸的冷调长曝光。交付为单个自包含 HTML，内联原生 SVG 为主体，画幅 16:9。页面在画布上方另有一条 **46px 高的顶部视图栏**：左侧标题、中部状态读数、右侧 7 个切换按钮（整体 / 配色 / 塔身 / 崖岸 / 线稿 / 爆炸图 / 标注），当前态按钮要有明显的选中样式。另有第 8 个状态「聚焦」由点击构件驱动、不占按钮位。

**截图一律整页截取（1536×864 的页面，含顶部视图栏），不是只截 SVG 画布**——视图栏和它上面 7 个按钮的当前态必须出现在每一张图里，画布居中于视图栏下方的剩余区域。截图集共 8 张。

本页只给**拓扑与因果**：不给任何路径坐标、渐变停靠点、半径或变换矩阵的现成数值。所有几何都必须由你从图像的透视关系里反解出来。images/ 下 8 张截图是同一插画的 8 个互补状态，画面事实一律以图为准。

img_004 岬角特写：推近到左侧岬角与塔基礁盘，可辨岩层接缝、明暗岩面、松林剪影与塔脚嵌进石缝的接触处。
img_005 线稿蓝图：场景填充全部剥掉，只剩青色描边，塔身内胆的轴、齿轮与环阵一览无遗；顶缘留一排刻度短线，画面仍是深底。此态下所有加性暖光——灯焰辉光核、外扩晕、光束、月面光带、浮尘光点、镜面光斑——一律熄灭到完全不可见。**画面里不得剩下任何非青色的填充块或辉光**：凡是在其它态里有实体填充的图元，此态一律改成空心青描边或直接熄灭；尤其注意**塔脚与近侧礁盘的接触处及其下方**（塔基座圈、接触阴影、环境光遮蔽这三样最容易漏改，原来都是暖棕半透明填充，只降不透明度会在塔脚留下一片棕灰斑），月面也只留一个冷青空心圆、不许留下灰盘。整幅图只应有深底 + 青色线 + 顶缘刻度。
img_006 分层爆炸：五层纵深底座沿同一条透视法线（近似指向画面右下）整体拉开，露出塔身内胆的轴、齿轮与环形构件。**五层各自沿这条法线的带符号偏移量必须两两不等、并且自外向内依次递增**——最外侧的环境场朝法线反方向拉得最远，其后每层依次少退一些，跨过外壳层之后转为正向、越靠外的层推得越远。于是画面上能数出五条互不重合的层带：环境场（天幕与海面）在最外，接触阴影层紧随，内胆层（内壁、轴与齿轮）居中，外壳层（塔身、岬角、礁盘）整体右移下移，镜面高光层推得最远。不允许两层用同一个偏移量、也不允许它们粘连成一坨。**每一层还要带一枚会跟着该层一起位移的层带标识**：一条从该层顶端竖直落到底部的虚线导轨，顶端挂一块小牌子，牌上写层号与该层层名（五块牌子沿竖直方向交错排布，不许横向叠在一起），牌子本身是本地坐标、位移要先扣掉，落点才不会跑偏。
img_007 部件标注：画面保持原样，**12 个编号圆标全部可见、一个不少**，每个圆标各引一条引线指向对应部件，右侧一条半透明索引面板按层列出各部件的编号、中英名与所属层号。**11 号「看守小屋」的圆标与引线必须落在画幅之内**，指向那块岬角岩顶上的小屋本体；被点到的构件要是画面上真实存在、看得见的东西，不能指向画外。任何圆标都不得被画幅边缘裁掉：锚点投影到画外时徽标要夹回画幅内。
img_008 聚焦态：点击塔身进入的聚焦状态——焦点件保持满不透明并沿其轮廓加一圈辉光，**其余全部部件不透明度降到 0.4 以下**（环境层、内胆层、外壳其余件、注记与屏幕读数一并退让），画面上只剩焦点件是亮的。退让要**逐图元生效、按连乘后的有效不透明度算**：灯室里的金色齿轮与灯焰、塔顶那圈光晕、月面，这些最亮的旁件即便自身不透明度是 1，只要父组降到 0.4 以下就算合格；反过来，若它们和焦点件共用同一个组，就会跟着满亮——分组时别把它们并进焦点件那一组。这一态不出现在视图栏里，由点击驱动；再次点击退回整体。

────────────────────────────────────────
二、空间透视拓扑（硬约束）

必须自建一台**三点透视的轨道相机**，用同一套投影函数生成全部图元；不允许逐件手摆屏幕坐标。

- 视轴略俯、方位角略偏左，于是所有竖直平行线在画幅上方收敛。凡是水平的圆环（塔身分节、栏杆立柱的顶面、穹顶肋、灯室箍环）在画面上都被俯视压扁成**椭圆**：远侧那半弧在上、弧度更平、线更细更暗，近侧那半弧在下、弧度更弯、线更粗更亮，两半在椭圆的左右极点接上，合成一个完整的扁椭圆——不是一条开口朝下的孤立弧线。
- 地平线落在画幅高度下方约三分之二处。天幕区（地平线以上、且位于背景层的部分）只允许出现环境层元素：天幕、月、星、云、飞鸟、远处光束。**背景层中不得有承重实体越过地平线向上冒头**（比如远景里不许冒出半个岛、半截柱子）。前景主体不受此限：灯塔塔身、岬角这类近处实物本就该遮住并穿过地平线，这是正常的遮挡关系，不算违例——判别标准是它在深度上属前景还是背景层，不是它的像素是否触到地平线。
- 塔身中轴落在画幅水平中线略偏左；岬角占据左侧三分之一并向右压住海面；月亮在右上象限。
- 相机距离固定，物件的屏幕大小只由它到相机的距离决定：并排的同高构件，远的必须更小、更靠近地平线。这条比例关系要在塔身、松林、礁石三处同时成立。

────────────────────────────────────────
三、遮挡深度因果（硬约束）

每个可辨识部件都必须带一个**深度键**（离相机越远值越大），并按「远者先落笔」入栈。验收时会在画幅上扫格点，逐点检查叠放次序与深度键是否一致——**任何一处「远处的压住近处的」都判失败**。至少要成立这些因果：

- 塔脚嵌进近侧礁盘：塔基与石头的接触处，石头在塔之上。
- 岬角压在远景海面与天幕之前；岬角自身的受光棱边敷在岩体之上。
- 塔身立在远景海面之前；前景礁石立在近海浪体之前。
- 灯室玻璃封在窗孔凹腔之前（凹腔是内胆层的深孔，玻璃是外壳层的面）。
- 光束是加性辉光，**故意**覆在塔身与天幕之上，不参与上述深度不变式。
- 远景飞鸟属环境层：一只极远处的鸟绝不能压在塔内构件之上。

同一层内部按深度键排序即可；跨层则由层序本身压过深度键（外壳永远盖住内胆），这是设计契约，不是深度推导的结果。

────────────────────────────────────────
四、五层纵深底座（Z 序分层，缺一不可）

逐层独立成组，组上标注层号与层名，层内每个部件再各自成组：

1. **环境场与背板底衬层**——天幕、星场、月与月晕、云、飞鸟、远景海面与浪带、暗角。
2. **基座承重与接触阴影层**——落地构件投在承载面上的接触阴影与环境光遮蔽椭圆；这些影子借用构件的名字成组，但必须标成非主角，聚焦高亮不得把它们当成焦点件。
3. **主构架与核心机构内胆层**——塔身内壁、轴、齿轮组、菲涅尔环阵、窗孔凹腔；这一层只在爆炸与蓝图视图里露脸。
4. **曲面外壳与多曲率包络层**——塔身外壳、环向涂装带、观景台与栏杆、灯室玻璃、穹顶与风向标、岬角、礁盘、碎浪岩群、松林、看守小屋、前景礁石。
5. **镜面高光与视差辉光层**——灯焰辉光核、光束、菲涅尔边缘光、浪脊高光、月面反射细闪、浮尘光斑。

这五层就是爆炸视图要拉开的那五条层带，层号即爆炸位移的排序依据。

────────────────────────────────────────
五、八类拓扑图元（每一类都要在 **至少一处** 图元上署名，八类齐备）

- `COMPLEX_BEZIER_CURVATURE` 复贝塞尔曲率：塔身、岬角、礁盘的旋转体外轮廓。
- `ISOMETRIC_INTERLOCKING_GEAR` 等距啮合齿轮：内胆里成对咬合的齿轮，齿要真的错位互锁。
- `AXIAL_ELLIPTICAL_ARRAY` 轴向椭圆阵列：沿轴等距排布的椭圆环（栏杆立柱、穹顶肋、塔身分节）。
- `LAYERED_CLIP_APERTURE` 分层剪影开口：用比真侧影略作外扩的轮廓做 clipPath，碎面怎么铺都咬不掉合法部分、外溢的一律被切掉。不得留下只声明不引用的空壳 clipPath。
- `TANGENTIAL_GRADIENT_SHEET` 切向渐变敷面：沿表面切向铺的渐变片（岩顶、浪裙、浪脊、塔身分面）。
- `CONCAVE_BORE_RECESS` 凹腔开孔：塔身上的窗孔是**凹进去**的孔，不是贴上去的圆点，要有孔壁的明暗与孔口的边光。
- `CHAMFERED_CROSS_COUPLING` 倒角十字联轴：内胆里带倒角的十字形联轴节。
- `ANAMORPHIC_SPECULAR_LENS` 变形镜面光斑：拉长的镜面高光与月面倒影细闪。

────────────────────────────────────────
六、五个 defs 库（下限）

- 线性渐变 ≥ 7 组；径向渐变 ≥ 5 组；剪影开口 clipPath ≥ 4 组；
- 蒙版 mask ≥ 3 组；滤镜 filter ≥ 1 组，且必须同时含 `feGaussianBlur` 与 `feMerge`。
- 渐变停靠点总数 ≥ 40。所有 `url(#…)` 引用必须落地；样式表里写了的类必须真的有图元在用，画出来的类必须真的有样式。

────────────────────────────────────────
七、光影材质映射

- 单一主光源（月亮）在右上。所有受光面朝向它，暗面一律转向左下，不得出现方向矛盾的高光。
- 每种材质都要有自己的**明暗两端**：塔身石砌是冷白到深灰，涂装带是砖红到焦褐，岩体是青灰到近黑，海面是靛青到墨。靠渐变与敷面把体积做出来，不许一片平涂。
- 灯焰是全场最亮的实体，须有辉光核 + 外扩晕 + 镜面光斑三层；月面是本场景第二亮，天幕是暗场。塔身与海面之间要保持足够的明度分离，否则塔会糊进背景。
- 岩体的碎面必须被剪影开口咬住，且单片跨度不得大到在特写下读成一片半透明玻璃。
- 暗角、接触阴影与环境光遮蔽都要压得住：下层暗部既不能糊成死黑，也不能亮到跟中层抢戏。

────────────────────────────────────────
八、微交互（五条全要）

1. 悬停：被指到的构件，其**外壳层**分组沿透视法线外移约 8px（不是整体位移，是按法线方向），离开后回到原位。
2. 视差：鼠标移动时，镜面高光层与环境层做**反向**微幅平移，形成视差光斑。
3. 聚焦：点击构件进入聚焦态（img_008），焦点件保持满不透明并给轮廓加辉光，**其余全部部件不透明度 ≤ 0.4**（读数与注记层一并退让）。判定看的是叠加父组之后的**有效不透明度**，所以灯焰、齿轮、月晕这类高亮旁件必须分在焦点件之外的组里。
4. 无损适配：画布在任何视口下等比缩放、水平垂直双向居中，切换视图后画幅比例不变。
5. 调色板切换：在高对比度与默认两套调色板之间整组切换，切换后构图与遮挡关系逐像素对齐。

────────────────────────────────────────
九、图元密度与体量约束（黑盒验收）

- 独立 `<path>` ≥ 120 条，闭合，`d` 不出现 `matrix(`。
- 单文件体量落在 70–120KB。
- 纯黑描边覆盖率必须为 0（`stroke:#000` / `black` / `#000000` 一律不允许）。暗部靠渐变与叠色压，不靠描黑边。
- 控制台报错为 0；`viewBox` 有效，缩放不糊。

────────────────────────────────────────
十、红线与实现约束

单个 HTML，CSS 与 JS 全部内联，字体用系统字体，完全离线可运行。**禁止** `<image>`、Base64 位图、`data:image/`、Canvas 截图、CSS 背景图冒充矢量，禁止 `iframe`/`srcdoc`。图形只能由 path 与基本图形配合渐变、clipPath、mask、filter 画出。部件按名分组并带 `id`/`data-*` 标记，层与部件可被脚本寻址。双击打开即显示，持续运行无未捕获错误。最终产物必须是一个 `.html` 文件。
