复现一幅矢量场景插画「潮汐灯塔 TIDAL BEACON」——夜潮海岸的冷调长曝光。交付为单个自包含 HTML，内联原生 SVG 为主体，画幅 16:9。画布上方另有一条 46px 高的顶部视图栏：左侧标题、中部实时审计读数、右侧 7 个切换按钮（整体 / 配色 / 塔身 / 崖岸 / 线稿 / 爆炸图 / 标注），当前态按钮要有明显选中样式。第 8 个状态「聚焦」由点击构件驱动，不占按钮位。

截图一律整页截取（1536×864，含顶部视图栏），不是只截 SVG 画布——视图栏与按钮当前态必须出现在每一张图里，画布居中于视图栏下方的剩余区域。images/ 下 8 张截图是同一插画的 8 个互补状态，**画面事实一律以图为准**。

本页只给**拓扑、因果、材质映射与黑盒验收**：不给任何 `<path>` 的 `d` 坐标、不给渐变停靠点（stop-color / offset）的现成数值、不给几何半径、不给变换矩阵。所有几何必须由你从图像的透视关系里反解。

二、顶部审计条（实时、可机读）

视图栏中部必须常驻一条实时读数，随每次视图切换、特写换框、窗口缩放立即刷新，禁止写死。文本形如：

`view=<状态键>  p=<path 数>  lg=<linearGradient 数>  rg=<radialGradient 数>  st=<stop 总数>  cp=<clipPath 数>  mk=<mask 数>  fl=<filter 数>  ly=<带 data-layer 的元素数>  vb=<当前 viewBox>`

- 状态键固定为 `overall | warm | tower | cliff | bp | explode | annot`；聚焦态不改变状态键。
- 所有计数必须来自对当前 DOM 的实时查询，切换视图后数值不得变化（除 `vb`），爆炸/聚焦也不得改变图元总数。
- 同时暴露 `window.LH.audit()`，返回与读数一致的平铺字段，并**必须**含以下结构化字段：
  - `uniquePath`：不同 `d` 字符串的数量；
  - `layers`：`{L1,L2,L3,L4,L5}` 各层后代元素数；
  - `prims`：八类 `data-prim` 各自的出现次数；
  - `defs`：`{linearGradient,radialGradient,clipPath,mask,filter}`，每项含 `{total,used}`；
  - `explode`：`{active, offsets:[L1…L5], monotonic:boolean}`；
  - `focus`：`{active, ids:[…], maxOther:number}`，`maxOther` 为当前聚焦态下非焦点可见图元的有效不透明度上确界。
- 另暴露 `window.LH.apply(状态键)` 供机审切换状态。读数、`audit()` 与真实 DOM 三者必须完全一致；连续切换全部状态三轮后，所有计数与 `uniquePath` 不得变化。
- 特写态（塔身 / 崖岸）通过**改变 viewBox 取景**实现，不得缩放、复制或重建图元；其余状态 viewBox 不变。

────────────────────────────────────────
三、空间透视拓扑（硬约束）

必须自建**一台三点透视的轨道相机**，用同一套投影函数生成全部图元；不允许逐件手摆屏幕坐标。

- 视轴略俯、方位角略偏左，所有竖直平行线在画幅上方收敛。验收在塔身、灯室、岬角岩柱三处各取一组本应平行的竖直轮廓线，向上延长后必须交于画幅上方同一收敛区（横向偏差不超过画幅宽度的 8%）；不允许各画各的灭点。
- 凡是水平的圆环（塔身分节、栏杆立柱顶面、穹顶肋、灯室箍环）在画面上都被俯视压扁成**椭圆**：远侧半弧在上、弧度更平、线更细更暗；近侧半弧在下、弧度更弯、线更粗更亮；两半在左右极点接上，合成完整扁椭圆——不是一条开口朝下的孤立弧线。验收会按椭圆上下半弧的线宽与明度做对比。
- 地平线落在画幅高度约三分之二处；以海天交界最长的水平线为准，其纵向位置必须落在画幅高度的 0.62–0.72 区间。天幕区（地平线以上、且属背景层的部分）只允许出现环境层元素：天幕、月、星、云、飞鸟、远处光束。**背景层中不得有承重实体越过地平线向上冒头**；前景灯塔、岬角穿过地平线属正常遮挡，判别看深度归属，不看像素是否触线。
- 塔身中轴落在画幅水平中线略偏左；岬角占据左侧三分之一并向右压住海面；月亮在右上象限。
- 相机距离固定，屏幕大小只由到相机的距离决定：并排同高构件，远的更小、更靠近地平线。该比例关系必须在塔身、松林、礁石三处同时成立；验收会比较三组同高参照物的屏幕高度随深度的单调递减。

────────────────────────────────────────
四、遮挡深度因果（硬约束）

每个可辨识部件都必须能推导出**深度键**（离相机越远值越大）。同一层内按深度键降序落笔（远者先画）；跨层由层序本身压过深度键——L1 永远最先落笔、L5 最后，外壳永远盖住内胆。这是设计契约，不是深度推导的结果。验收会在画幅上扫格点，逐点比对「谁盖住谁」与层序 / 文档顺序是否一致——**任何一处「远处的压住近处的」都判失败**。

至少要成立这些因果：

- 塔脚嵌进近侧礁盘：塔基与石头的接触处，石头在塔之上。
- 岬角压在远景海面与天幕之前；岬角自身的受光棱边敷在岩体之上。
- 塔身立在远景海面之前；前景礁石立在近海浪体之前。
- 灯室玻璃封在窗孔凹腔之前（凹腔是内胆深孔，玻璃是外壳面）。
- 光束是加性辉光，**故意**覆在塔身与天幕之上，不参与上述深度不变式。
- 远景飞鸟属环境层：极远处的鸟绝不能压在塔内构件之上。

────────────────────────────────────────
五、五层纵深底座（Z 序分层，缺一不可）

逐层独立成组，组上标注层号与层名（`#L1`…`#L5`，均带 `data-layer`），层内每个部件再各自成组。

1. **环境场与背板底衬层**——天幕、星场、月与月晕、云、飞鸟、远景海面与浪带、暗角。
2. **基座承重与接触阴影层**——落地构件投在承载面上的接触阴影与环境光遮蔽椭圆；这些影子借用构件的名字成组，但必须标成非主角，聚焦高亮不得把它们当焦点件。
3. **主构架与核心机构内胆层**——塔身内壁、轴、齿轮组、菲涅尔环阵、窗孔凹腔；只在爆炸与蓝图视图露脸。
4. **曲面外壳与多曲率包络层**——塔身外壳、环向涂装带、观景台与栏杆、灯室玻璃、穹顶与风向标、岬角、礁盘、碎浪岩群、松林、看守小屋、前景礁石。
5. **镜面高光与视差辉光层**——灯焰辉光核、光束、菲涅尔边缘光、浪脊高光、月面反射细闪、浮尘光斑。

这五层就是爆炸视图拉开的那五条层带，层号即爆炸位移的排序依据。另可增设拾取面、注记等非纵深组（如图中所示），但它们不得混入五层的遮挡链。

六、八类拓扑图元（八类齐备，且达到最低署名数）

- `COMPLEX_BEZIER_CURVATURE` 复贝塞尔曲率（≥70 处）：塔身、岬角、礁盘的旋转体外轮廓。
- `ISOMETRIC_INTERLOCKING_GEAR` 等距啮合齿轮（≥3 处）：内胆里成对咬合的齿轮，齿要真的错位互锁。
- `AXIAL_ELLIPTICAL_ARRAY` 轴向椭圆阵列（≥25 处）：沿轴等距排布的椭圆环（栏杆立柱、穹顶肋、塔身分节）。
- `LAYERED_CLIP_APERTURE` 分层剪影开口（≥60 处）：用比真侧影略作外扩的轮廓做 clipPath，碎面怎么铺都咬不掉合法部分、外溢的一律被切掉；不得留下只声明不引用的空壳。
- `TANGENTIAL_GRADIENT_SHEET` 切向渐变敷面（≥50 处）：沿表面切向铺的渐变片（岩顶、浪裙、浪脊、塔身分面）。
- `CONCAVE_BORE_RECESS` 凹腔开孔（≥12 处）：塔身窗孔是**凹进去**的孔，不是贴上去的圆点，要有孔壁明暗与孔口边光。
- `CHAMFERED_CROSS_COUPLING` 倒角十字联轴（≥10 处）：内胆里带倒角的十字形联轴节。
- `ANAMORPHIC_SPECULAR_LENS` 变形镜面光斑（≥20 处）：拉长的镜面高光与月面倒影细闪。

每个图元用 `data-prim="类别名"` 署名。署名图元必须真实参与绘制（有面积或描边），不得用零尺寸占位符刷数。

七、defs 库（下限，且全部落地）

- 线性渐变 ≥ 52 组；径向渐变 ≥ 10 组；渐变停靠点总数 ≥ 200；不同 `stop-color` 的去重值 ≥ 150。
- 剪影开口 clipPath ≥ 4 组；蒙版 mask ≥ 3 组；滤镜 filter ≥ 3 组，其中至少 1 组必须同时含 `feGaussianBlur` 与 `feMerge`，其余可只用模糊。
- 每个 clipPath、mask、filter、渐变都必须被至少一个图元真实引用（`audit().defs` 中 `used === total`）；所有 `url(#…)` 必须解析到存在的 id。
- 去重后的实体 `fill` 值（不含 `none` / `transparent`）≥ 32 种；去重后的 `stroke` 值 ≥ 6 种。材质必须真的分层，不许全图只有三五种颜色。
- 样式表里写了的类必须真的有图元在用；画出来的类必须真的有样式。禁止孤立 defs 与僵尸类。

────────────────────────────────────────
八、光影材质映射

- 单一主光源（月亮）在右上。所有受光面朝向它，暗面一律转向左下，不得出现方向矛盾的高光。
- 每种材质都要有自己的**明暗两端**：塔身石砌是冷白到深灰，涂装带是砖红到焦褐，岩体是青灰到近黑，海面是靛青到墨。靠渐变与敷面把体积做出来，不许一片平涂。
- 灯焰是全场最亮实体，须有辉光核 + 外扩晕 + 镜面光斑三层；月面是第二亮；天幕是暗场。塔身与海面之间保持足够明度分离，否则塔会糊进背景。
- 岩体碎面必须被剪影开口咬住，单片跨度不得大到在特写下读成一片半透明玻璃。
- 暗角、接触阴影与环境光遮蔽都要压得住：下层暗部既不能糊成死黑，也不能亮到跟中层抢戏。

九、微交互与状态机（五条微交互全要，另加四项交互契约）

1. 悬停：被指到的构件，其**外壳层分组**沿透视法线外移 6–12px（与爆炸视图同一条法线，夹角 ≤ 5°，不是整体平移），离开后 700ms 内回到原位，残余位移 ≤ 1px。
2. 视差：鼠标移动时，镜面高光层与环境层做**反向**微幅平移，且镜面高光层的位移绝对值必须大于环境层；两层的位移随指针位置连续变化。
3. 聚焦：点击任一构件进入聚焦态（img_008），焦点件满不透明并加轮廓辉光，**其余全部部件的有效不透明度 ≤ 0.4**（画布内读数与注记层一并退让，顶部视图栏常亮）。12 个拾取区必须逐一可聚焦，`audit().focus.ids` 不得为空；再次点击、按 Esc、或点击画布空白处均退回整体。
4. 无损适配：画布在 4:3、16:9、21:9 三种视口下都等比缩放、水平垂直双向居中；宽高比误差 ≤ 0.1%，画布中心与容器中心偏差 ≤ 1px，切换视图后不糊、不裁。
5. 调色板切换：默认与高对比两套调色板整组切换；切换后构图与遮挡关系逐像素对齐，20 个抽样部件的包围盒偏移 ≤ 0.5px。

**交互契约（机审直接触发）**：

- 视图栏 `role="toolbar"`；7 个按钮的 `aria-pressed` 必须与当前态同步（当前态 `true`，其余 `false`）。
- 键盘 `1`–`7` 切换七个视图，`Esc` 退出聚焦；键盘焦点落在任一拾取区时，`Enter` 或空格必须触发与该拾取区点击相同的聚焦行为。
- 12 个拾取区必须带 `tabindex="0"`、`role="button"` 与可读的 `aria-label`（含部件名），且不改变画面像素。
- `prefers-reduced-motion: reduce` 生效时，视差位移必须归零（L1/L5 的 `transform` 回到零位移），过渡动画关闭；普通模式下不得误触发。

────────────────────────────────────────
十、黑盒验收（机审直接测，不看你如何实现）

1. **透视收敛**：三组竖直轮廓向上延长交于画幅上方同一收敛区，横向偏差 ≤ 8% 画宽。
2. **环阵压扁**：所有水平圆环在画面上呈闭合扁椭圆，远半弧比近半弧更细更暗；出现开口孤弧或上下半弧等粗等亮即失败。
3. **地平线**：海天交界最长水平线落在画幅高度 0.62–0.72。
4. **比例随深度递减**：塔身、松林、礁石三组同高参照物的屏幕高度随纵深单调递减。
5. **遮挡一致**：格点扫描的覆盖关系与层序 / 文档顺序零冲突。
6. **爆炸单调**：`audit().explode.monotonic === true`；五层偏移量两两不等、自 L1 至 L5 严格递增，且在外壳层处由负转正；五块层带牌与各自层的位移逐位相等；五条导轨在爆炸态仍为竖直直线（包围盒宽 ≤ 1px），不得被斜切。
7. **聚焦连乘**：非焦点的可见绘制图元（有填充或描边；`fill:none` / `transparent` 且无描边的拾取面不计）按祖先 opacity 连乘后的有效不透明度全部 ≤ 0.4；`audit().focus.maxOther ≤ 0.4`；焦点件 ≥ 0.9。
