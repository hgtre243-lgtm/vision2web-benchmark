一、五大环形强耦合子系统（≥ 5 个，缺一不可，且必须互相读取对方状态，不得各自孤立）
1. 非欧微气象与动力学矢量解算核心：风场必须是随高度反向、随水平位置切变、随相位周期演化的非均匀矢量场，严禁用恒定常数加减来伪造风力。风场同时向守卫输出水平推力与竖直分量，并受一个可压缩的切变周期控制——腐化爆发窗期间该周期被压缩到常态的五分之一以下。守卫当前的相对气流方向由"风矢量与自身水平速度的点积符号"判定，并据此改写跳跃与弹射的受力，判定结果必须逐帧显示在左栏"守卫读数"与右栏风切罗盘上。
2. 多实体物理衰变与反作用力系统：每列地块有承重上限与弹簧刚度、阻尼；塔与守卫都会给所在地块加载，承重超过该列上限即进入"失稳"，失稳地块被守卫离开后点燃引信，引信到期即碎裂为不可站立的虚空（该列的有效地表随之下降）；未失稳地块的完整度随时间自然衰变，且受守卫着陆冲击速度影响——冲击越猛，完整度损失越大。守卫与地块之间必须双向作用：不仅地块影响守卫，守卫的落点位置与离块动作也必须反向改写该列的沉陷量与寿命；相邻列的沉陷必须在同一帧内互相可见。
3. 主动式能量循环与过载熔断引擎：动能绝对严禁随时间自然恢复，处于静止、待机或无波次时不得有任何正向回充；稳定性储备同样不得自然回充。动能仅在两处获得——精准踏中地块中心的共鸣核心区、或成功完成空中能量索摆荡；蓄能弹射、磁极翻转与蓄能越限三者扣减动能，而地块边缘区的落点与静止驻留扣减的是稳定性储备，两类扣减不得混为一谈。长按蓄能超过阈值即触发过载，产生操作硬直并在硬直期内屏蔽全部输入，同时清空跃迁充能。
4. 多实体空间拓扑与分层判定系统：每一列地块在水平方向上至少分为三层判定——居中的共鸣核心区（占格宽居中 20%）、其外的边缘区、以及已碎裂的完全不参与判定的虚空。核心区与边缘区的落点后果必须相反（一方按离差加权返还动能与营养，一方按每秒 5% 持续扣减稳定性储备），严禁"按键即清场"或"落地即通关"。魔物的命中判定必须区分"核心受击点 / 擦弹边缘 / 动量吸收域"，弹体命中不同层产生不同伤害与不同反作用力。
5. 逐帧事件溯源与结算审计账本：逐帧累积一条样本记录（时间戳、坐标、速度、动能、稳定性、核心生命、营养、击杀与漏怪计数、腐化值、潮汐相位、塔数、在场魔物数、在场总血量、开火次数、累计伤害、地块平均完整度、共振达标塔数、本帧落点离差）。台账与结算面板上的根脉守护、落点精准、动能效率、共鸣连锁率与风场利用率五项，必须在汇总时对该数组回溯聚合得出，不得由与帧序列无关的独立计数器直接产出；帧样本数必须恒等于该数组的长度。所有分数、评级与金币式资源结算必须由该审计数组经纯函数式聚合得出，严禁写死数值。

三、多画布独立渲染与专业 HUD 架构（≥ 3 块独立画布 + ≥ 5 个仪表视窗）
至少三块画布各自拥有独立的绘制循环与高低不同的重绘频次，共享同一份内存物理态：画布 A 主视窗承载地块、圣泉节点、塔、弹体、魔物、守卫、粒子与全部世界叠加层；画布 B 动态 HUD 仪表阵列，逐帧重绘；画布 C 环境雷达与走势带，以显著低于主视窗的频率重绘，呈现古道剖面与列号、圣泉节点、塔位、魔物位置、危险预警以及本局走势折线。结算雷达另用一块独立画布，只在结算时绘制。画布 B 内至少含六个独立仪表模块：① 风切矢量罗盘（风速读数、风矢量箭头，以及"索载摆荡中 / 逆风升力向量 / 顺风阻尼放大 / 静风无攻角"四态之一的文字标注）；② 动能示波雷达（近段动能样本折线与归一化读数）；③ 地块寿命倒计时环形条（当前承载列编号、沉陷量与承重比，地块失稳时环形条转为引信倒计时）；④ 过载压力标尺（含 PERFECT 判定窗区间、实时蓄能毫秒数与硬直剩余毫秒数）；⑤ 共鸣链蓄能槽（固定七格，第 i 格对应当前第 i 座防御塔的共振进度，未建位为空槽，达标整格点亮）；⑥ 相位与腐化面板（磁极与重力系数、腐化值、射程折减百分比、翻转冷却、按键映射是否已反向）。仪表读数必须逐帧随物理态刷新，不得有静态占位值。

四、复合高阶交互操作手势（≥ 5 种，每种都必须有可观察的即时响应）
1. 动量压制蓄能弹射：长按压缩形体，画面给出蓄能环与判定窗弧，松手按蓄能量非线性弹出（蓄能量越大，弹射初速以平方关系放大）；落入判定窗内另有倍率加成，越限则转入过载硬直。
2. 空域能量索抓取与摆荡释放：向空中的圣泉锚点射索后按单摆运动摆荡，可收索提速；张力按离心项与重力分量合成并实时显示在左栏与仪表上，超限即绷断；自选脱离角释放切向速度，成功完成摆荡会返还动能。
3. 动量下压速坠冲击：空中按下压键，下坠加速度随当前下落速度递增，终端降落速度大幅提高，落地时显著加深该列沉陷并触发扩散震荡波。
4. 空间相位瞬时翻转：翻转磁极使重力系数与左右按键映射同时反向，并叠加一段视差倾角扰动，带冷却时间；磁极极性必须同时出现在左栏读数与仪表面板上。
5. 韧根共振主动同调：同调完成后按键，清空当前地块的剩余寿命以换取一次全屏动能脉冲，脉冲对范围内魔物造成伤害并弹起守卫，同时把该地块计入碎裂。
另需三枚键盘单键：跳跃、暂停、返回标题。

五、黑盒验收规范（自动化测试会植入探针，下列三条为硬性断言）
1. 接触同调时延：落脚在任何可站立地块表面之后，绝对严禁立即重置二段跳或跃迁充能次数。必须在落点维持相对静止（水平与垂直线速度的绝对值均小于 0.05）累计不少于 350 毫秒、同调进度满格之后，跳跃次数才由 0 置为 1；进度未满时一切跳跃与弹射指令必须被驳回，并给出与成功时明显不同的可观察反馈（左栏"跃迁充能"保持 0 / 1（未激活））。探针会在触地后 200 毫秒发跳跃指令，若该指令被成功执行即判定核心机制未实现。
2. 零被动恢复与静止消耗：在零输入、静止待机、无波次的状态下持续 3 秒，动能池、稳定性储备与战斗得分三项均不得出现任何正向增长（结算流程不在此列）。动能只按离差加权来自核心区命中与能量索摆荡。与之镜像的是，守卫在地块边缘区（共鸣核心区之外）静止驻留时，稳定性储备按每秒 5% 持续扣除；储备归零时该地块立即转为失稳。
3. 反常识风阻与下沉反冲力学：空域存在横向切变风。在按键输入完全相同的前提下，顺风时水平阻尼被非线性放大到满攻角 1.40 倍、跃迁初速的垂直分量同时被压制，跳跃距离显著缩短；逆风时迎风夹角产生向上升力矢量，跳跃高度与滞空时间显著提升——两种工况的差异必须能被观测量测出，且两者都必须与无风基准形成可量化对比。地块的下沉速度必须严格满足 v_sink = 1.2 × (1 + v_impact² / 200)，并设有上限钳制。守卫离开地块的瞬间，地块必须向反方向弹起位移，弹力系数 k = 0.68；若该地块已失稳，引信自离块瞬间起算，500 毫秒到期即碎裂为不可站立虚空，并被计入结算的碎裂地块数。反冲只发生在离块瞬间，落地瞬间不得触发。

数值与实现口径：本卷只规定上述响应关系与因果关系，不给出引擎基准常量（重力加速度、起跳初速、蓄能满档时长、PERFECT 判定窗上下沿、各塔射程与冷却、各魔物血量与赏金等一律由实现方自行选定，但必须与上述响应关系自洽）。结算的五项指标采用五轴加权，权重与评级分档同样不出题面，只需做到"由逐帧样本数组回溯聚合、同种子同输入逐帧可复现"。

红线
- 交付单个 .html 文件，CSS 与 JS 全部内联，双击离线可运行；不得出现任何外部脚本、样式表、字体、图片、音频或网络资源。所有图像必须由 Canvas 代码程序化生成，所有音效必须由 Web Audio API 纯代码合成。
- 不得使用 iframe、srcdoc，不得使用任何第三方游戏框架或物理引擎。
- 物理必须由逐帧速度与加速度积分产生，固定步长推进；不得使用现成的具名缓动函数替代物理解算。
- 所有随机量必须由固定种子驱动的确定性伪随机数发生器产生，同种子同输入逐帧可复现；禁止使用系统随机源。
- 禁止弹窗类阻塞接口与向文档流写入内容；不得出现占位文本、未实现的空壳面板或与真实数据不符的读数。
- 页面启动与持续运行期间，控制台不得出现任何未捕获异常、脚本错误或资源加载失败。
