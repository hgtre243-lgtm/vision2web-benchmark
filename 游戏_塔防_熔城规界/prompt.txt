━━ 四、六个环形强耦合子系统 ━━
1. 地脉准线相位解算：相位在 [0,1) 推进，一周切四段，四段交替取两个互异常值斜率，且两斜率之和为 2、之积为 1/2——因此解析周期严格恒定、不随帧率漂移。前半程导内环航线，后半程导外环；同时给出射程倍率与敌速倍率，两者严格反相，并在右栏倍率示波上逐帧显示。跨段必须做时间切分，不得用一段斜率替代整帧推进。每次跨越换相边界都产生一次可观测的换相事件并计数。
2. 瞄准锥伺服与落空判定：每塔维护瞄准角，逐帧向准线角缓动；角差必须先归一化到 [−π, π) 再比较，否则越过整圈后判定永久失效。只有"目标方位与瞄准角之差 < 该塔锥半角"才命中，超出即落空并写事件流。锥半角与射程实时读取子系统 3 的结渣值。
3. 热力—结渣—重铸引擎：开火积热、持续散热；积热越过上限即过热，射速被压低直到回落到解锁阈值。每次过热与漏怪都累积结渣；结渣按归一化比例折减全场射程、收窄锥半角，并让后续波次额外加派魔物（增量必须在"本波情报"逐帧可读）。花费炉金发动重铸脉冲：清空结渣并锁定准线相位一段时间——子系统 3 反向改写 1 与 2。
4. 地块衰变与反作用：每格有完整度与沉陷；塔与熔核都会加载。落地冲击越大，沉陷越深、完整度损失越大；完整度跌破阈值转失稳；失稳格被熔核离开的瞬间点燃引信，到期碎裂为不可站立虚空，格上塔一并坠毁并写事件流。未失稳格完整度随时间自然衰变；相邻格的沉陷在同帧互相可见。
5. 炉芯耦合与同调：只有站上或建在炉芯八邻格才累积耦合，达标后全场伤害获得加成倍率（逐帧显示）。落点分核心区（格宽居中固定比例）与边缘区：核心区按离差加权返还动能并退还该格塔积热，边缘区按固定每秒比例持续扣稳定度。
6. 逐帧溯源审计账本：每帧一条 22 列样本（时间戳、坐标、高度、动能、稳定度、炉壁、结渣、均温、击杀、漏怪、相位、塔数、在场数、在场总血、开火、累计伤害、地块均完整度、耦合达标塔数、本帧离差、守恒缺口、风切强度）。结算五项与三张主指标卡必须由该数组纯函数式回溯聚合，帧样本数恒等于数组长度；"落点精准"在无落点样本时必须判为无定义并如实标注，不得以满值冒充。

━━ 五、五科目整数守恒账（不得旁路） ━━
五个科目：炉金 / 熔铁 / 动能 / 结渣 / 熵损，全部以整数记账（1 点资源 = 100 单位）。任何经济行为——建造、升级、出售、击杀赏金、伤害入账、蓄能/翻转/摆荡/制动的动能变化、共振、兑换、置换、提前出波——都必须走**同一条双边转账函数**，从一科目扣、向另一科目加。
恒等式：五科目之和恒等于固定总额 1000000，守恒缺口恒等于 0。该等式必须逐帧落入账本第 21 列，并在底部"五科目整数守恒账"画布上以比例带 + 逐科目整数 + Σ + 缺口四段显示。严禁直接改写单科目余额；任何旁路都会让缺口非零，即判缺陷。

━━ 九、黑盒探针（自动化测试会植入，三条硬断言） ━━
1. 接触同调时延：熔核落到任何可站立地块后，**绝对禁止立即重置跃迁次数**。落块瞬间先进入同调挂起；只有相对静止（水平与垂直速度都低于静止判据）持续**满 350 ms** 之后，跃迁次数才恢复。探针会在触地后 **t = 200 ms** 发出跃迁指令：若被执行即判核心机制未实现，直接扣 D3。实测：200 ms 时同调进度约 0.286 且跳跃返回 false；400 ms 时放行。
2. 零被动恢复 + 边缘静止扣减：零输入、静止、无波次持续 3 秒，动能、稳定度、炉金、账本任何科目都**不得出现正向增长**（同调完成只恢复跃迁次数，绝不回充动能）。镜像地，熔核在地块边缘区静止时稳定度按每秒 5% 持续扣除；核心区静止时不得有任何正向回充，且损耗率显著低于边缘区。
3. 反常识风阻与下沉反冲：空域是非均匀矢量场（禁止常数加减伪造）。相同输入下顺风把水平阻尼非线性放大到 **×1.40**、并压制垂直初速；逆风由迎流夹角产生升力，跳跃高度与滞空显著提升。下沉速率 `v_sink = 1.2 × (1 + v_impact² / 200)`，随冲击速度超线性增长并钳制上限。离块瞬间地块反向弹起，弹跳/离块速度比固定为 **k = 0.68**（只在离块触发，落地不触发）；失稳地块自离块起算引信，**500 ms** 后碎裂为虚空并计入结算。

━━ 十、红线 ━━
- 交付单个 .html，CSS/JS 全内联，双击离线可运行；禁止外部脚本、样式、字体、图片、音频、网络资源；所有图像由 Canvas 程序化生成，音效由 Web Audio 纯代码合成。
- 禁止 iframe/srcdoc、第三方框架或物理引擎。
- 物理必须逐帧速度—加速度积分，固定步长；禁止用现成缓动函数替代解算。
- 所有随机量由固定种子驱动的确定性 PRNG 产生，同种子同输入逐帧可复现；禁止系统随机源。
- 禁止弹窗类阻塞接口与 document.write；不得出现占位文本、空壳面板或与真实数据不符的读数。
- 全生命周期控制台不得出现未捕获异常、脚本错误或资源加载失败。

━━ 十一、验收 ━━
基准版式 1536×864；实测覆盖 1024 / 1152 / 1280 / 1366 / 1440 / 1600 / 1920 / 2560 八档宽度，均不得出现横纵向溢出，主视窗、状态横幅与全部仪表在这些宽度下都必须可见。
基础可运行性四项缺一不可：文档可被语法解析且无未闭合标签；1280×720 下可成功启动；主视窗实际绘制出可检测的非白、非纯黑图形；从加载到交互的全生命周期控制台无未捕获异常。软件光栅化下持续运行 60 秒平均帧率不低于 25 帧/秒，首帧不得为白屏或黑屏。
另加四条数值断言：自检 14/14 通过且用时落在 1.0–1.6 s；全 14 态可由探针逐一到达且枚举名与决策表逐字一致；60 秒内账本守恒缺口恒为 0；同种子同输入两次运行的账本逐帧一致。
