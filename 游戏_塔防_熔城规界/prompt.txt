本条对下列各项指标强制生效，与主任务描述同等约束。

一、五大环形强耦合子系统（≥ 5 个，缺一不可，且必须互相读取对方状态，不得各自孤立）
1. 地脉准线相位解算核心：相位在 [0,1) 上推进，且推进率不是常数——一周切成四段，四段内交替取两个互异的常值斜率，并须满足"两段斜率之和为 2、之积为 1/2"，从而使解析周期严格恒定、不随帧率漂移。相位前半程把魔物导向内环航线、后半程导向外环航线；相位同时给出射程倍率与敌速倍率，两者必须严格反相（一个取极大时另一个取极小），两者都必须逐帧显示在右栏"历史收益倍率账本"上。每一次相位跨越换相边界都必须产生一次可观测的"换相"事件并计入换相次数。离散积分必须做跨段边界的时间切分，严禁用一段的斜率替代整帧推进，否则实测周期会系统性偏离解析周期。
2. 瞄准锥伺服与落空判定系统：每座塔维护一个持续增长的瞄准角，逐帧向准线当前角度缓动爬行（角度差必须逐次归一化到 [−π, π)，严禁直接对累积角取模，否则瞄准角越过一整圈后判定会永久失效）。塔只能命中"目标方位与瞄准角之差小于该塔锥半角"的目标，超出一律判落空并在事件流里留下"偏差 <角度> ≥ 锥半角 · 落空"的记录。该系统的锥半角会被结渣收窄、射程会被结渣折减，因此它必须实时读取子系统 3 的状态。
3. 热力—结渣—重铸经济引擎：每座塔每开火一次积热，同时全塔持续散热，积热超过上限即触发"过载"——该塔射速被显著压低，直到积热回落到一个解锁阈值以下才恢复；每次过载与每次漏怪都向全场累积"结渣"。结渣会按归一化比例折减全场射程并收窄全场锥半角，且每泄漏一只魔物都会为后续波次额外加派魔物（该增量必须逐帧显示在右栏"本波情报"的"结渣额外增员"）。玩家可花费炉金发动"重铸脉冲"，一次性清空结渣并把准线相位锁定一段时间——于是子系统 3 反向改写子系统 1 与 2。
4. 多实体物理衰变与反作用力系统：每一格地块有完整度与沉陷量；塔与熔核都会给所在地块加载。熔核着陆的冲击速度越大，该格沉陷越深、完整度损失越大；完整度降到阈值即转为"失稳"，失稳地块被熔核离开的瞬间点燃引信，引信到期即碎裂为不可站立的虚空，且该格上的塔一并坠入虚空（事件流记"地块碎裂 · 塔体坠入虚空 (列,行)"）。未失稳地块的完整度随时间自然衰变。熔核与地块必须双向作用：不仅地块影响熔核，熔核的落点位置与离块动作也必须反向改写该格的沉陷量与寿命；相邻格的沉陷必须在同一帧内互相可见。地块塌成虚空会删掉塔，从而反向加重子系统 3 的结渣压力。
5. 炉芯耦合与熔核同调系统：熔核站上（或塔建在）炉芯节点的八邻格时才累积炉芯耦合，耦合达标后全场塔的伤害获得一个加成倍率（该倍率必须逐帧显示在右栏"历史收益倍率账本"的"炉芯耦合加成"一行）。熔核的落点分为居中的炉芯核心区（占格宽居中比例固定）与其外的边缘区，两区后果相反：核心区按离差加权返还动能并退还该格塔的积热，边缘区按一个固定的每秒比例持续扣减稳定度储备。
6. 逐帧事件溯源与结算审计账本：逐帧累积一条样本记录（时间戳、熔核坐标与高度、速度、动能、稳定度、炉壁结构、结渣、全塔平均积热、击杀与漏怪计数、准线相位、塔数、在场魔物数、在场总血量、开火次数、累计伤害、地块平均完整度、耦合达标塔数、本帧落点离差）。台账与结算面板上的炉壁守护、落点精准、结渣控制、同调链与峰值抑制五项，必须在汇总时对该数组回溯聚合得出，不得由与帧序列无关的独立计数器直接产出；帧样本数必须恒等于该数组的长度。所有分数、评级与炉金式资源结算必须由该审计数组经纯函数式聚合得出，严禁写死数值。当落点样本数为零时，"落点精准"无定义，必须判为不计入并如实标注，不得以满值冒充满分。

状态由单一枚举承载，任一帧只取一个值，判定优先级自上而下、高位压制低位；顶栏状态读数、视口状态横幅、右栏决策表高亮行三者必须逐帧一致。严禁用一堆全局布尔变量杂糅出状态。

三、多画布独立渲染与专业 HUD 架构（≥ 3 块独立画布 + ≥ 5 个仪表视窗）
至少三块画布各自拥有独立的绘制循环与高低不同的重绘频次，共享同一份内存物理态：画布 A 主视窗承载棋盘、熔岩管网、炉芯节点、塔、瞄准锥、弹体、魔物、熔核、粒子与全部世界叠加层；画布 B 动态 HUD 仪表阵列，逐帧重绘；画布 C 环境雷达，以显著低于主视窗的频率重绘，呈现棋盘剖面与列号、管网、炉芯节点、塔位、魔物位置、危险预警以及准线亮带。走势带与结算雷达另用各自独立的画布，结算雷达只在结算时绘制。画布 B 内至少含五个独立仪表模块：① 地脉气流矢量罗盘（流速读数、气流方向箭头，以及"顺流 / 逆流 / 静风"等工况的文字标注）；② 地块寿命倒计时环形条（当前承载格编号、沉陷量与承重比，地块失稳时环形条转为引信倒计时）；③ 多段连击蓄能槽（固定数格，第 i 格对应当前第 i 座防御塔的蓄能进度，未建位为空槽，达标整格点亮，并给出 PERFECT 判定窗的毫秒区间、实时蓄能毫秒数与 PERFECT 次数 / 落点次数）；④ 实时损耗率监视器（给出当前每秒的结构损耗率读数与近段折线）；⑤ 历史收益倍率账本（逐行给出准线射程倍率、准线敌速倍率、结渣射程惩罚、气流流量阻尼、炉芯耦合加成，各带 × 前缀）。仪表读数必须逐帧随物理态刷新，不得有静态占位值。

四、复合高阶交互操作手势（≥ 5 种，每种都必须有可观察的即时响应）
1. 动量压制速坠冲击：空中按下压键，下坠加速度随当前下落速度递增，终端降落速度大幅提高，落地时显著加深该格沉陷并触发扩散震荡波。
2. 张力蓄能非线性弹射：长按压缩形体，画面给出蓄能环与判定窗弧，松手按蓄能量非线性弹出（蓄能量越大，弹射初速以平方关系放大）；落入判定窗内另有倍率加成，越限则转入过载硬直。
3. 空间相位瞬时翻转：翻转磁极使重力极性与移动手感同时反向，并叠加一段短暂但可观测的视差倾角扰动（时长由实现方自定），带冷却时间；当前重力极性必须同时出现在左栏读数与仪表面板上。
4. 空域能量索抓取与摆荡释放：向空中的地脉枢纽射索后按单摆运动摆荡，可收索提速；张力按离心项与重力分量合成并实时显示，超限即绷断；自选脱离角释放切向速度，成功完成摆荡会返还动能。
5. 浮屿共振主动同调：站上炉芯节点八邻格且同调完成后按键，清空该格剩余寿命以换取一次全屏动能脉冲，脉冲对范围内魔物造成伤害并把熔核弹起，同时把该格计入碎裂。
另需三枚键盘单键：跃迁（须先完成同调）、暂停、返回标题。

五、黑盒验收规范（自动化测试会植入探针，下列三条为硬性断言）
1. 接触同调时延：熔核落在任何可站立地块表面之后，绝对严禁立即重置跃迁次数。落块瞬间必须先进入同调挂起，只有在落点维持"相对静止"（水平与垂直线速度都小到足以判定为静止，具体判据由实现方自定，但必须逐帧可读）并累计满一段可由观测量测出的驻留时间之后，跃迁次数才由 0 置为 1；驻留未满时一切跃迁与弹射指令必须被驳回，并给出与成功时明显不同的可观察反馈（左栏"剩余跃迁次数"仍为空）。该驻留时长必须显著长于触地瞬间。自动化测试会在触地后的极早期——远早于任何合理的同调完成时刻——发出跃迁指令，若该指令被成功执行即判定核心机制未实现。
2. 零被动恢复与静止消耗：在零输入、静止待机、无波次的状态下持续一段足以暴露任何被动回充的时间，动能池、稳定度储备与熔炼得分三项均不得出现任何正向增长（结算流程不在此列）。动能只按离差加权来自炉芯核心区命中与能量索摆荡。与之镜像的是，熔核在地块边缘区（炉芯核心区之外）静止驻留时，稳定度储备按一个固定的每秒比例持续扣除（比例由实现方自定，但必须逐帧可读）；储备归零时该格立即转为失稳。另需满足：熔核在核心区静止时不得出现任何正向回充，其稳定度损耗率必须显著低于边缘区，两者之差必须能被观测量测出。
3. 反常识风阻与下沉反冲力学：空域存在非均匀矢量气流场（严禁用恒定常数加减来伪造风力）。在按键输入完全相同的前提下，顺风时水平阻尼被非线性显著放大到满攻角的一个远大于 1 的倍率（倍率由实现方自定）、跃迁初速的垂直分量同时被压制，跳跃距离显著缩短；逆风时迎风夹角产生向上升力矢量，跳跃高度与滞空时间显著提升——两种工况的差异必须能被观测量测出，且两者都必须与无风基准形成可量化对比。地块的下沉速度必须随着陆冲击速度呈超线性增长（冲击速度翻倍时沉陷量的增长必须远超过一倍），而不是线性增长，并设有上限钳制；同一地块在两组不同冲击速度下的实测沉陷必须能反推出这条关系。熔核离开地块的瞬间，地块必须向反方向弹起位移，弹跳速度与离块速度之比是一个由实现方选定的固定比例常数（反冲只发生在离块瞬间，落地瞬间不得触发）；若该地块已失稳，引信自离块瞬间起算，经过一段固定的引信时长后碎裂为不可站立虚空，并被计入结算的碎裂地块数。

数值与实现口径：本卷只规定上述响应关系与因果关系，不给出引擎基准常量（重力加速度、跃迁初速、蓄能满档时长、PERFECT 判定窗上下沿、各塔射程与冷却、各魔物血量与赏金、积热与散热速率、过载解锁阈值、结渣折减系数、准线周期与两段斜率的具体取值、下沉速度与冲击速度关系式中的系数、离块反冲的比例常数、引信时长、同调最小驻留时长与静止判据的阈值、边缘区稳定度扣除速率、顺风阻尼放大倍率、视差扰动时长等一律由实现方自行选定，但必须与上述响应关系自洽）。结渣折减、耦合加成、漏怪加派等各项倍率只需做到"逐帧可读、可由观测量反推"。结算的五项指标采用加权合成，权重与评级分档同样不出题面，只需做到"由逐帧样本数组回溯聚合、同种子同输入逐帧可复现"。注意：其中一部分阈值与倍率可以"从参考图上读到"（例如驻留毫秒数、气流流量阻尼与炉芯耦合加成的 × 倍率、PERFECT 判定窗的毫秒区间、能量索射程）——凡图上可读的，一律以图为准并与图保持一致；图上读不到的，才由实现方自行选定。

红线
- 交付单个 .html 文件，CSS 与 JS 全部内联，双击离线可运行；不得出现任何外部脚本、样式表、字体、图片、音频或网络资源。所有图像必须由 Canvas 代码程序化生成，所有音效必须由 Web Audio API 纯代码合成。
- 不得使用 iframe、srcdoc，不得使用任何第三方游戏框架或物理引擎。
- 物理必须由逐帧速度与加速度积分产生，固定步长推进；不得使用现成的具名缓动函数替代物理解算。
- 所有随机量必须由固定种子驱动的确定性伪随机数发生器产生，同种子同输入逐帧可复现；禁止使用系统随机源。
- 禁止弹窗类阻塞接口与向文档流写入内容；不得出现占位文本、未实现的空壳面板或与真实数据不符的读数。
- 页面启动与持续运行期间，控制台不得出现任何未捕获异常、脚本错误或资源加载失败。
