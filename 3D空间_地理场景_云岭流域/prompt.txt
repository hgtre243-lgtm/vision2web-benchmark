本条对下列四项指标强制生效，与主任务描述同等约束：

一、原生底层五大环形强耦合子系统（≥ 5 个，缺一不可）
1. 原生图元装配与缓冲管线：动态建立顶点坐标、法线、切线、顶点颜色、纹理坐标与索引六类缓冲；流域块体的顶点总数不得少于 1500，且必须是由连续曲面法线支撑的三角网格，非平面法线、非逐面常量法线。
2. 手搓变换矩阵与非欧视锥：用单精度浮点数组自行构造透视投影矩阵、观察矩阵与模型旋转平移复合矩阵，逐帧上传给着色器，禁止依赖任何第三方矩阵或向量数学库。存储布局、叉乘方向或极点兜底任一处写错，场景都会被近远裁面整片剔除而全黑。相机为球面极坐标相机，极角必须硬限位。
3. 双动态点光源着色管线：在片元阶段实现环境项、漫反射项与半程向量高光项。两个点光源的距离衰减必须为非线性平方反比型（近场不得过曝、远场不得截断）；主光绕场景公转构成日照方向，副光为补色边缘逆光，两者张角不得小于 30 度。曲面凹凸由切空间法线摄动提供，法线摄动强度与高光指数必须运行时可调，且归零时回落到几何法线的平滑着色。
4. 射线拾取与空间解算：把指针视口坐标换算为归一化设备坐标，乘投影视图逆矩阵反解出世界空间射线，与七座标石的包围体求交，并与流域曲面求交得到地表落点。悬停与双击聚焦均由该结果驱动。
5. 实时遥测与空间审计账本：逐帧累积时序样本（累计时间、帧间隔、当前状态枚举、是否命中实体、是否发生有效拾取）。账本上的帧样本数、平均帧间隔、拾取命中率与状态驻留直方图四项，必须由该序列在汇总时回溯聚合得出，不得由与帧序列无关的独立计数器直接产出；直方图各柱之和必须恒等于帧样本总数。

三、五大三维控制台专业 UI 模块（≥ 5 个独立视窗）
拒绝简陋的网页文字堆砌，必须是与画布深度融合的三维工作台参数 HUD，读数逐帧随物理态刷新，不得有静态占位值：① 空间相机方位仪（世界坐标 x/y/z、球面方位角与极角、视距、注视靶点）；② 双动态光源三维轨道示波图（两光源的轨道历史轨迹折线、当前相位标记、世界坐标、强度、距离衰减常数与主副光张角）；③ 几何体表面曲率与法线摄动强度微调滑块面板（法线摄动强度、高光指数、等高线密度三组连续滑块，滑动即时改写着色参数并立即反映在画面上，另附线框叠加与光照过载两个瞬时触发按钮）；④ 视锥体参数监视窗（视场角、宽高比、近裁面与远裁面距离、靶点处的近远深度、相机到几何包围体的间隙量、剔除状态）；⑤ 渲染管线监控面板（当前图元类型、各缓冲装配数量、顶点属性通道、顶点总数、三角形面数、每帧绘制调用数、着色器程序数、纹理采样单元、深度与剔除状态、实时帧率与帧间隔）。

四、复合高阶三维交互手势（≥ 5 种微操，核心交互覆盖率须 100%）
1. 左键球面环绕：拖拽中持续估读角速度，松手后必须带物理转动惯量继续滑行并按指数阻尼平滑衰减，自由滑行时长不得低于 800 毫秒；不得在指针事件里直接对旋转角做增量赋值而松手即停。
2. 滚轮非线性缩放：阻力随视距逼近近裁面而指数级增大，视距硬限位。
3. 右键平移靶点：在相机屏幕平面内平移注视靶点，相机世界坐标随之整体平动。
4. 双击射线聚焦：由拾取结果驱动相机沿插值轨迹推进至实体表面。
5. Shift 拖拽牵引副光：把次级动态光源沿空间球面轨迹重定位，实时改写其入射方向与主副光张角，极角硬限位。
另需三枚键盘单键：过载、线框混合、视锥归位。
防穿模硬断言：无论方位角、极角与视距如何，相机到几何包围体表面的距离必须始终钳制在 d ≥ 0.5 单位，禁止穿入几何体内部导致背面剔除露空。

红线
- 交付单个 .html 文件，CSS 与 JS 全部内联，双击离线可运行；不得出现任何外部脚本、样式表、字体、图片、模型文件或网络资源。
- 不得引入任何第三方三维渲染库或三维数学库，全局作用域内不得残留此类标识符。
- 画布上下文必须是原生 webgl 或 webgl2；文档中只允许存在一块画布，全部 HUD、仪表、示波图与直方图由 DOM 与内联矢量图形承载。用二维上下文描线冒充三维的，判定未实现三维核心渲染。
- 几何体、法线摄动贴图与全部顶点数据必须由 JavaScript 在运行时用数学算法生成并写入类型化数组，不得硬编码顶点数组，不得使用任何位图资源。
- 所有相机运动必须由逐帧速度与阻尼积分产生，不得使用现成的具名缓动函数或插值公式。
- 禁止弹窗类阻塞接口与向文档流写入内容；不得出现占位文本、未实现的空壳面板或与真实数据不符的读数。
- 页面启动与持续运行期间，控制台不得出现任何未捕获异常、脚本错误或资源加载失败。
