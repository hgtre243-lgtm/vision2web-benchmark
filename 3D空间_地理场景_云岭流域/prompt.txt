云岭流域 YUNLING WATERSHED · 原生 WebGL 三维地理分析沙盘（单文件网页）。整屏深色地理信息工作台，一块有厚度的流域地质块体、七座八棱锥台标石、双动态点光源、手搓空间变换、射线拾取与逐帧审计账本共同构成一个可交互的三维场景。images/ 下 8 张 1536×864 截图为同一次会话内的 8 个互斥状态，画面与图中读数是唯一准绳；题面只规定拓扑、因果、度量与黑盒验收，不提供任何可直接誊抄的几何数组、着色器源码或矩阵乘法源码。

本题强制执行原生 WebGL 5-8-5-5 架构：5 个环形强耦合子系统、8 阶互斥状态机、5 类以上 HUD 模块、5 种复合手势。四项与主任务同等约束，任一不达即视为未完成。

━━ 一、世界与跨图不变量 ━━
流域块体为 4096×4096 世界单位的方形地质块，控制网格 97×97；地表三角网格、四侧向下挤出的底座裙边、七座八棱锥台标石共同组成场景，总顶点数不得少于 1500，法线必须是连续曲面法线而非逐面常量。地表按高程分层设色：湖盆深青蓝 → 河谷绿 → 山坡土黄 → 山脊浅灰 → 雪线白，并叠加随高度截断的等高线晕渲；外围环状山脊，中部塌陷成盆谷，一条主河道自西北向东南切穿山脊出山，低处蓄水成湖。
七座标石及其归一化落点 (u,v) 与体量系数固定为：主峰 · 云岭顶 (0.205,0.196,1.45) / 次峰 · 白石尖 (0.782,0.238,1.15) / 湖心 · 沉沙泊 (0.462,0.612,1.00) / 隘口 · 风门口 (0.148,0.556,0.92) / 汇流 · 三江口 (0.508,0.436,0.88) / 出山 · 龙门峡 (0.556,0.088,1.06) / 观测 · 中继台 (0.858,0.812,0.80)。落点高度必须由同一高程场采样，标石底面与地表的最大落面误差不得大于 2 单位；每座标石有独立包围球，半径随体量缩放，拾取浮层显示其半径与命中距离。
四个取景预设固定为：全景鸟瞰 / 北向侧掠 / 湖盆俯视 / 峡谷低掠。四者分别对应高角全景、低角侧掠、接近俯瞰与极低角贴地掠射；切换预设必须走与归位相同的插值轨迹，不得瞬移。
双动态点光源：主光为暖色日照、绕场景公转，副光为冷色补色逆光、以不同角速率独立公转；两者张角不得小于 30°。距离衰减必须是非线性平方反比型，近场不得过曝、远场不得硬截断；两个衰减常数的具体取值只以 img_002 右栏“衰减常数 k₁/k₂”的读数为准，题面不复述。右下着色面板的法线摄动强度、高光指数、等高线密度三组滑块必须实时改写画面；归零时回落到几何法线的平滑着色。
八图之间只允许出现这些差异：状态枚举、相机方位角/极角/视距/注视靶点、两光源相位与强度、着色滑块与过载状态、图元混合模式、账本读数、拾取浮层内容。品牌、字体、栅格、面板分栏、按钮文案、配色与所有仪表标签不得漂移。

━━ 三、八阶互斥有限状态机（全决策表） ━━
状态由单一枚举承载，任一帧只取一值；判定优先级自上而下，高位压制低位。顶栏状态链高亮、视口左上状态横幅、右栏“当前状态”三处必须逐帧显示同一英文枚举名。严禁用多个布尔量杂糅出状态。

| 优先级 | 状态 | 进入条件 | 维持期约束 | 退出/后继 |
|---|---|---|---|---|
| 1 | FRUSTUM_RESET_HOMING | 归位/预设插值计时 > 0 | 姿态、视距、靶点、FOV 沿轨迹复位，暂不响应惯性 | 计时归零 → 低一优先级 |
| 2 | ENTITY_FOCUSED_ZOOM | 已由拾取结果锁定某实体且聚焦计时 > 0 | 相机与靶点插值推进，禁止巡航自转 | 驻留结束 → 低一优先级 |
| 3 | CAMERA_ORBIT_DRAGGING | 主键按住环绕，或右键按住平移靶点 | 球面姿态/靶点随指针阻尼跟随，逐帧估读角速度 | 松手 → 惯性滑行或低一优先级 |
| 4 | TARGET_ENTITY_HOVER | 本帧屏幕射线命中某标石包围球 | 该实体预选高亮，拾取浮层更新 | 射线离开 → 低一优先级 |
| 5 | LIGHTING_OVERDRIVE | 过载计时 > 0 | 主光强度、高光与泛光同时跃升 | 计时归零 → 低一优先级 |
| 6 | SHADING_WIREFRAME_HYBRID | 线框计时 > 0 | 线段骨架叠加，图元与绘制调用同步改写 | 计时归零 → 低一优先级 |
| 7 | INIT_BUFFER_ALLOCATED | 启动自检链尚未闭合 | 指针交互锁定，场景不可操作 | 链闭合 → ORBIT_IDLE_SPINNING |
| 8 | ORBIT_IDLE_SPINNING | 其余情形 | 相机沿默认轨道匀速巡航自转，无惯性残留 | 任意高位状态 |

任一时刻只允许一个状态高亮；状态驻留直方图的八个柱子必须与此枚举一一对应。

━━ 四、五个环形强耦合子系统（缺一不可） ━━
1. 原生缓冲与拓扑引擎：运行时用数学算法生成顶点位置、法线、切线、顶点色、纹理坐标与索引六类数据并写入类型化数组；地形、裙边、标石各自成网格，索引缓冲按图元装配；线框模式另有一份去重线段索引。页面必须真实持有至少 16 个静态顶点缓冲与 6 个索引缓冲，且渲染管线面板的 VBO/EBO 计数由实际创建动作计数，不得写死。缓冲的包围盒与顶点/三角面计数是下游矩阵、拾取与账本的输入。
2. 手搓空间变换与非欧视锥：自行构造透视投影、观察与模型复合矩阵，逐帧上传；相机为球面极坐标相机，方位角自由、极角硬限位、视距硬限位。投影-观察矩阵与其逆的乘积必须逼近单位阵；任一帧的相机方位角加 90° 后，实体屏幕位置必须随相机一致旋转，场景不得全黑、不得镜像、不得出现背面剔除露空。矩阵手性、转置、叉乘方向或极点兜底任一处错误都会导致整片近远裁面剔除。
3. 双点光源的 Blinn-Phong 着色：片元阶段计算环境项、漫反射项与半程向量高光项；两个点光源的强度、坐标、相位逐帧由各自的轨道积分推进；法线由切空间摄动叠加到几何法线，摄动强度与高光指数运行时可调。主光过载时强度、高光与泛光同步上升；副光只改补色边缘，不夺主光方向。光源张角、衰减读数由右栏示波图逐帧显示。
4. 射线拾取与空间解算：把指针的视口坐标换算为归一化设备坐标，反解世界空间射线，先与七座标石的包围球求交，再与流域曲面求交得到地表落点；命中结果必须当帧写入拾取浮层、状态机与账本。悬停与双击聚焦只能由该结果驱动，禁止用屏幕距离或预置区域伪造命中。
5. 逐帧遥测与审计账本：每帧向一个 16 列样本数组追加一条记录，账本的五项聚合全部在该数组上回溯得出；任何一项都不得由独立计数器直接产出。账本同时反向驱动状态驻留显示与命中率，形成闭环。

━━ 五、十六列账本与聚合恒等式 ━━
每帧样本恰好 16 列，顺序固定：累计时间戳 t / 定长步长 dt(ms) / 状态枚举 / 是否命中实体(0/1) / 是否发生有效拾取(0/1) / 方位角 / 极角 / 视距 / 注视靶点 x / y / z / 角速度模 / 相机到包围盒间隙 / 主光相位 / 副光相位 / 三角面数。列名不得重复，账本标题右侧显示“16 列”。
聚合恒等式：帧样本数 ≡ 数组长度；步长均值 = 全部 dt 的算术均值，且固定步进下恒为 16.67 ms；拾取命中率 = 命中帧数 ÷ 有效拾取帧数 × 100%，有效拾取帧数为 0 时必须判为“无定义”，显示“无定义 —”，不得用 0% 或 100% 冒充；状态驻留直方图八柱之和恒等于帧样本总数；状态转移次数 = 相邻样本状态枚举变化次数；最小包围盒间隙 = 全时段第 13 列最小值，均值 = 第 13 列算术均值；平均角速度 = 第 12 列均值。
底部账本五卡固定为：帧样本数 / 平均帧间隔 / 拾取命中率 / 状态驻留分布（八柱 + Σ 帧数 + 转移次数）/ 最小包围盒间隙（阈值 0.50 单位与全时段均值）。五卡数值必须与上述数组一致。

━━ 六、HUD 模块（≥5 类，全部逐帧刷新） ━━
① 空间相机方位仪：世界坐标 x/y/z、方位角 AZ、极角 EL、视距 DIST、注视靶点、角速度 ω。
② 视锥体参数监视窗：视场角 FOV、宽高比 ASPECT、近裁面 NEAR、远裁面 FAR、靶点处近/远距离、相机到包围盒间隙 d、剔除状态。
③ 渲染管线监控面板：图元装配类型、顶点缓冲数、索引缓冲数、属性通道、顶点总数、三角面数、每帧绘制调用数、着色器程序数、采样器单元、深度/剔除状态、实时帧率、帧间隔。
④ 双动态光源三维轨道示波图：两条椭圆轨道历史折线、当前相位标记、主/副光世界坐标、强度、衰减常数、主副光张角、两光源轨道相位。
⑤ 曲率与法线摄动强度面板：法线摄动强度、高光指数、等高线密度三组连续滑块，另附线框叠加与光照过载两个瞬时按钮；滑块位置、读数与画面必须同步。
⑥ 着色与交互状态面板：当前状态、该状态驻留帧数、拾取对象、对象状态矩阵、着色模型、交互模式、惯性滑行剩余时间、视距阻力倍率。
另加底部五卡账本与顶栏四读数（帧率 / 三角面 / 视距 / 图元）。全部读数逐帧随物理态刷新，不得有静态占位。

━━ 七、五种复合手势与三枚单键 ━━
1. 左键球面环绕：拖拽中逐帧估读角速度，松手后必须保留角速度并按指数阻尼继续滑行，自由滑行时长不得低于 800 毫秒；禁止在指针事件里对旋转角做增量赋值而松手即停。
2. 滚轮非线性缩放：视距随滚轮改变，越接近近裁面阻力越大，形成指数级缓冲；视距上下限硬限位，禁止越过近裁面或穿入块体。
3. 右键平移靶点：在相机自身的屏幕平面内平移注视靶点，相机世界坐标同步整体平动，姿态不变。
4. 双击射线聚焦：由拾取结果驱动相机沿插值轨迹推进至实体表面，推进过程中保持朝向该实体。
5. Shift + 拖拽牵引副光：把次级点光源沿空间球面轨迹重定位，实时改写入射方向与主副光张角，极角硬限位。
单键：L 光照过载、W 线框混合、R 视锥归位。四枚取景预设按钮与三枚单键在面板中的文案必须与左下手势提示条一致。
防穿模硬断言：无论方位角、极角与视距如何组合，相机到场景包围盒表面的距离必须始终钳制在 d ≥ 0.5 单位；最大俯冲缩放时也不例外。背面剔除不得露出块体内部。

━━ 八、十二级启动自检链 ━━
启动后先在视口上跑一条 12 级自检链，逐级实测、逐级留痕；任一级 FAIL 则整链重跑且不交接渲染循环。级别顺序与必须当场算出的量：
DOM_PROBE（必需节点绑定数）→ CANVAS_CONTEXT（原生 WebGL 上下文类型与画布数）→ BUFFER_ASSEMBLY（地形 + 裙边 + 标石顶点数）→ SURFACE_TOPOLOGY（相邻法线最小点积）→ TANGENT_FRAME（法线与切线的正交残差上界）→ MATRIX_CORE（投影观察矩阵与其逆的乘积最大偏差）→ CLIP_RANGE（靶点投影后的归一化深度与齐次 w）→ LIGHT_LAW（三个距离上的衰减单调性 + 主副光张角）→ ENTITY_MOORING（七座标石与地表的落面误差）→ RAY_PICK（把某实体反投影回屏幕再拾取，必须命中该实体并给出 t）→ LEDGER_SCHEMA（16 列且列名无重复）→ PIXEL_HANDSHAKE（读取画布像素的均值、标准差与颜色数，必须非空白）。
每行注记必须是当场计算出的数字，不得写死；全链闭合用时必须落在 1.0–1.6 s，且页脚显示实测用时。自检期间账本可显示自检样本，但闭合瞬间必须整体清空，正式账本从零开始累积。

━━ 九、黑盒探针（三条硬断言） ━━
1. 库与上下文雷：全局作用域不得出现 THREE / BABYLON / glMatrix / mat4 任一标识符，不得有外部 script/link/img 或网络请求；画布上下文必须是 webgl 或 webgl2，且全页只允许一块画布。用 2D 上下文描线、分层贴图或 CSS 3D 冒充三维的直接判未实现。
2. 手搓矩阵雷：启动时投影-观察矩阵与其逆的乘积最大偏差必须小于 1e-3；把相机方位角分别加、减 90° 后重新拾取同一实体，两次屏幕位置必须与相机旋转因果一致，场景不得全黑、不得整片镜像、不得把内表面翻到外面。奇异、转置或手性错误的矩阵会触发 D1 门禁直接判 0。
3. 惯性与穿模雷：左键拖拽后松手，位移事件停止；松手后 100 ms 与 800 ms 两个时刻的角速度都必须仍为正，滑行不得在事件结束时立刻归零（立刻停止扣 D3）。把视距推到最近端时，相机到包围盒间隙必须仍 ≥ 0.5 单位；相机穿入块体、背面剔除露空或地平线撕裂均判严重缺陷。

━━ 十、红线 ━━
- 交付单个 .html，CSS/JS 全内联，双击离线可运行；禁止外部脚本、样式、字体、图片、模型或网络资源。
- 禁止引入任何第三方三维渲染库或三维数学库；全局不得残留此类标识符。
- 全部几何、法线、切线与法线摄动纹理必须由 JavaScript 运行时用数学算法生成并写入类型化数组；禁止硬编码顶点数组与位图资源。
- 画布上下文必须是原生 WebGL；HUD、示波图、直方图由 DOM 与内联 SVG 承载。
- 所有相机运动必须由逐帧速度与阻尼积分产生，固定 60 Hz 步长推进，禁止现成缓动函数、CSS 过渡或直接赋值旋转角替代解算。
- 禁止弹窗类阻塞接口与 document.write；不得出现占位文本、空壳面板或与真实数据不符的读数。
- 全生命周期控制台不得出现未捕获异常、脚本错误或资源加载失败。

━━ 十一、验收 ━━
基准版式 1536×864；实测覆盖 1024 / 1152 / 1280 / 1366 / 1440 / 1600 / 1920 / 2560 八档宽度，均不得出现横向或纵向溢出，三维视口、状态横幅与全部仪表在这些宽度下都必须可见。
基础可运行性四项缺一不可：文档可被语法解析且无未闭合标签；1280×720 下可成功启动；主视口实际绘制出可检测的非白、非纯黑图形；从加载到交互的全生命周期控制台无未捕获异常。软件光栅化下持续运行 60 秒平均帧率不低于 25 帧/秒，首帧不得为白屏或黑屏。
数值断言：自检 12/12 通过且闭合用时落在 1.0–1.6 s；八个状态可由探针逐一到达且英文枚举名与决策表逐字一致；任意时刻仅一个状态高亮；账本 16 列、八柱之和恒等于帧样本数、无有效拾取时命中率显示无定义；最小包围盒间隙恒 ≥ 0.50 单位；同一会话内启动闭合后账本帧数单调不减。固定 60 Hz 步进下，冻结画面后以相同输入序列推进，两次运行的账本逐帧一致。
上文全部断言以最终成品实测为唯一判据，不以说明本身为准。题面、8 张参考图与实现三者必须完全自洽；图上看不清的数字与文案不得臆造成确定事实，能由物理量算出的必须给出当场算出的值。
