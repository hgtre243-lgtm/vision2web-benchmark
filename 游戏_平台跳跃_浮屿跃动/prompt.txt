「浮屿结构余量合计 Σ(每座实时结构余量) ＋ 舱体动能储备 ＋ 已转成功 ＋ 崩解熵增损耗 ≡ 标定总量 120.000」，
差额必须逐帧恒为零。任何一次动能获得都必须同时是一次等量的结构余量减少，不允许凭空生成；任何一次不可回收的亏损都必须整份转入崩解熵增损耗科目。四科目之间只允许「搬运」与「转科」两类操作：搬运不改变总和，转科把一份余额从可回收科目移入不可回收科目，两者都不改变总和。额定吸能速率、单次跨气层抽取额度、单次驻屿同调抽取额度、蓄能脉冲消耗额度、静置泄漏速率、边缘驻留扣减速率全部为固定常量，且必须由同一处常量表统一管理，不得散落在各子系统内各自写死一份。

**共鸣链**：浮屿按色相分为三系（青绿 / 琥珀 / 紫极），三系交替落点的序列构成一条固定的七段共鸣链。落点色相与链上当前期望段一致即推进一段，不一致即断链并把链计数清零；链深度直接改写结算的共鸣连锁得分与实时收益倍率。链的期望序列、当前进度与断裂次数必须同屏可见。

**磁极与相位**：弦舱有一个磁极相位，翻转后重力矢量与左右键映射同时反向，并附带一段固定时长的视差倾角扰动；相位瞬切是另一条完全正交的机制——它把重力矢量按当前象限额外改写，并在同一段固定时长内叠加一层横向视差力，两者共享时长常量但改写对象互不相同，必须能同时生效且互不覆盖。

【第二层：五个环形强耦合子系统】五个子系统同时存在、串接成环：任何一次跃迁、落屿、抽取、驻屿、跨带、锚定、翻转、瞬切、脉冲、共振或提交都必须同时改变全部五个子系统的输出，不允许其中任何一个被静态数据绕过，也不允许某个子系统只在特定状态下才参与运算。

系统一 · 非欧微气象与动力学矢量解算核心。以固定种子派生的风场行波为核心，逐帧解算空域内任意点的风矢量（含水平分量与垂直分量），并叠加五大气层的切变增益、涌流增益与承重增益；风矢量同时作用于弦舱受力、浮屿承重、能量索摆荡的切向流与雷达的风场箭头。本系统的输出必须反向改写系统二的衰变速率（顺风压制会放大水平阻尼，逆风升力抬高法向载荷从而改变承重）、系统三的吸能速率（风压做功计入动能储备的收支）、系统四的区位判定（风把弦舱推离核心区从而改变档位）与系统五的事件流（每一个风场里程碑都要落账）。子流首值与折叠摘要必须可被外部读取，且随种子或时间相位变化。

系统二 · 多实体物理衰变与反作用力系统。120 座浮屿各自维护下沉位移、下沉速度、承重与磨损；弦舱落屿的那一帧按下落速度的平方压缩出下沉冲击，冲击反过来抬升该屿的下沉目标位移与磨损率，并在落点生成一圈随时间扩张消散的震荡波。浮屿被抽取结构余量后寿命下降，寿命进入低位即标记失稳，失稳屿在弦舱离屿后进入固定时长的崩解引信，引信归零即整份崩解并把残余结构余量全部转入崩解熵增损耗（不可回收）。弦舱离屿的瞬间还获得一份与落屿压缩量同源的向上反冲，反冲系数为固定常量；下沉中的浮屿会把驻留其上的弦舱一并带落。本系统的输出必须反向改写系统四的判定结果（失稳屿不再提供核心区档位）、系统三的收支（崩解是纯亏损）与系统五的归约结果。

系统三 · 主动式能量循环与过载熔断引擎。动能储备只能通过「从浮屿抽取结构余量」这一条路径获得，且一次抽取量恒等于该次动作的定额；储备随蓄能按键长按按非线性张力增长，而在待机坞中长按蓄能会把抽到的结构余量直接注入储备并推进接手进度，满档即接手传动。储备贴顶即为越限：越限部分不经回收，整份转入崩解熵增损耗，同时施加一段过载硬直并冻结全部输入。蓄能脉冲消耗固定额度的储备换取一次瞬时上升，若储备不足或同调锁定值未越门限则必须驳回并在账本上留下一条拒绝事件。本系统不提供任何被动回复：静置时储备按额定速率持续向熵增流失，边缘驻留时按稳定性比例额外扣减，两者都是纯亏损。

系统四 · 多实体空间拓扑与分层判定系统。以每座浮屿的锚域感应半径为准，把弦舱所处的水平位置切成三档——核心区（半径的固定低位比例为界）、中庭带、边缘带；半径之外为 OFF。档位直接决定驻屿同调能否累积、抽取额度取多少、边缘驻留是否扣减稳定性、雷达上是否画出危险预警。浮屿的下沉位移、视觉尺度与锚域感应半径随高度带变化，判定必须逐帧以当前实时半径为准，不得缓存上一帧的档位。本系统的输出必须反向改写系统三的收支（核心区抽取额度高于非核心区）、系统二的寿命（边缘驻留进入失稳路径）与系统五的落点归约。

系统五 · 逐帧事件溯源与结算审计账本。每一帧的每一个可归约动作都必须在账本上落一条带时间戳、消息与权重的条目，条目在结算时以纯函数归约出全部读数，不得读取任何实时状态。账本另维护一枚可分段折叠的校验和：对空账折叠必须等于固定基线 `0x811c9dc5`；对同一账本做整段折叠与任意切分的分段折叠必须逐位相同，重复折叠同一账本必须恒等。事件流水的可见条数有上限（超出即截尾，只保留最近若干条），但归约必须始终基于完整账本而非可见截尾。结算通道由「两阶段提交」把守：先把当前账本前缀的快照（条数、校验和、当时的科目差额）暂存为一笔待提交事务，再在固定复核窗口内以提交动作复核同一段前缀——超窗、差额非零或校验和与暂存值不一致，三种情形都必须驳回事务、把校验失败次数加一并锁死校验通道一段固定时长；通道锁定期间只受理一次「守恒审计」（把四个科目从零重数一遍），审计通过才解锁并把失败次数清零。本系统的输出必须反向改写系统三的结算条件、系统四的收益归约与系统一的气象利用占比。

**环的闭合方向**必须写死在实现里：系统一 → 系统二 → 系统四 → 系统三 → 系统五 → 系统一。也就是说，风场改写衰变，衰变改写区位，区位改写收支，收支改写账本，账本又通过收益倍率反写风场的利用系数。任何一次闭环断裂（例如账本翻倍于实时读数、或抽取量与实际余额不符）都必须在差额读数上暴露出来，差额一旦非零即视为实现错误。

【第四层：4 块独立画布、14 个仪表视窗、8 种复合手势】

四块画布必须各自拥有独立的 2D 上下文与独立的后备缓冲区尺寸，且后备尺寸恒等于逻辑尺寸乘以该画布声明的倍率；不得把四块画布的内容合并到一块画布上用裁剪区伪装。

画布 A（主视窗）：逻辑 952×580，倍率 1，逐帧重绘。绘制浮屿阵列、天锚、风场流线、弦舱、震荡波、粒子与全部世界层特效。
画布 B（跃动仪表阵列）：逻辑 304×240，倍率 1，逐帧重绘。绘制风切矢量罗盘、动力演示雷达、浮屿寿命倒计时环、过载压力指示器、共鸣链蓄能槽与实时损耗率监视器六个小仪表。
画布 C（浮屿寿命阵列）：逻辑 304×120，倍率 2，每 6 帧重绘。以固定列数 × 固定行数画出全部 120 座浮屿的结构余量占比柱。
画布 D（空域雷达）：逻辑 246×206，倍率 2，每 10 帧重绘。绘制局部高度窗、窗内浮屿、气层分界线、历史航迹、视野框与远端危险预警；结算态改绘五轴归约雷达图。

十四块仪表视窗同时常驻，各自独立刷新，且至少有两处的刷新频率明显高于主视窗（画面须能看出不同步）：

一、风切矢量罗盘：以极坐标画出当前风矢量的方向与模长，并给出「静风 / 驻屿 / 顺风压制 / 逆风升力」的四态判定文字与数值；进入切变风廊时整盘描边转为紫色。
二、动力演示雷达：以归一化速度 |v| / 巡航速度为唯一口径画出实时速度包络与一条滑动历史曲线；本仪表的口径即全题的静止判据口径，两者必须同源。
三、浮屿寿命倒计时环形条：对当前承托屿画出剩余寿命占比的环形条，并对已进入引信的浮屿画出读秒；寿命低于低位时环条转为警示色。
四、过载压力指示器：画出动能储备 / 上限的条形与蓄能窗口（下限 / 上限的毫秒区间），并在越限时整条转为警示色；须给出「待机 / 上升 / 越限」三态。
五、多段连击蓄能槽：把共鸣链的期望段逐段画成独立格，已推进的段点亮，当前期望段以脉冲描边标出，断链时整槽闪红并把计数清零。
六、实时损耗率监视器：给出当前崩解熵增损耗占总量的比例、以「每秒」为单位的瞬时增长率与一调「上限」读数；损耗率的每一次跃变都必须能追溯到账本上的具体条目。
七、浮屿寿命阵列：以固定列数 × 固定行数的网格画出全部 120 座浮屿的结构余量占比柱，存活屿按余量高低分三档着色，崩解屿画为暗色并加一道横杠，被弦舱占据的屿在柱顶加一条高亮线；底部另起一行给出「存活数 / 总数 · 累计熵增」读数，柱体绝不允许压到这两行文字上。
八、能量索预演双轨仪：给出预演采样点数、实锚采样点数、「同源观测 / 越界」发数与「峰值偏差 / 容差」两栏；未锚定时显示「未生成 · 待 0 锚定」。
九、结构预算守恒账本：逐行列出四科目余额、「四科目合计 / 标定」与「差额（必须恒为 0）」，并在卡片标题栏常驻给出「差额徽标 · 浮屿座数」读数；差额非零时该徽标必须转为警示色。
十、历史收益倍率账本：以表格逐行列出同调等级、风场拟合、磁极对冲、共鸣连锁、浮屿损耗、风廊加成各自的实时倍率与依据，表头给出总倍率。
十一、空域气层协议剖面仪：逐带列出带号、带名、切变 / 涌流读数与感应增益，当前带高亮；表下给出当前带的完整读数行（含锚域感应半径、需求槽位占用、风廊是否生效、天锚座数、跨带累计次数）。
十二、空域风切 · 磁极场：逐行给出「风速 / 攻角」「相对气流」「跳跃效应」「终端降落速度」「磁极 / 重力」「承托浮屿」六项实时读数。
十三、空域雷达与小地图：必须是一张局部拓扑视窗而不是整条空域的压缩图：以弦舱当前高度为中心取一段有限的高度窗，只绘制窗内浮屿、窗内风场抽样箭头、五条气层分界线（并在每条线旁标注带号）、弦舱的历史航迹折线、当前视野框（虚线矩形）与弦舱位置（带脉冲环）；窗内每座浮屿只有在「被弦舱占据」「已失稳」或「已崩解」三种情形下才允许标注编号，其余一律不标号，禁止把 120 组编号压在同一张画布上。底部必须给出「高度窗 起→止 · 视窗内 n 座 · 失稳 m」的读数。结算态下同一块画布改绘为五轴归约雷达图（落点精准度 / 浮屿完整度 / 能量周转效率 / 共鸣连锁 / 气象利用），并给出综评分与等级。
十四、事件溯源流水：逐条滚动显示带时间戳与权重的事件，高亮当前状态迁移条目；可见条数有上限，超出即截尾。

**八种复合手势**（每一项都必须是多键位、多阶段的组合，而非单键触发）：

一、动量下压速坠冲击：空中按下压键，下坠加速度逐帧递增至压缩终端速度，落点生成扩张消散的震荡波并按冲击强度反噬该屿的承重与下沉目标位移。
二、非线性张力蓄能弹射：长按蓄能键压缩形体，蓄能按非线性张力增长并从周边浮屿抽取结构余量，满格接手传动；蓄能期间浮屿的衰变与风场推进照常。
三、空间相位瞬时翻转：翻转磁极使重力矢量与左右键映射同时反向，并附带一段固定时长的视差倾角扰动。
四、空域能量索抓取与摆荡释放：射向锚域感应半径内的天锚后按单摆方程以固定子步数积分摆荡，收索提速，自选脱离角释放切向速度。
五、浮屿共振主动同调释放：同调完成后按共振键，把该屿剩余结构余量整份泄放为崩解熵增损耗换取一次全屏动能脉冲；该屿随即进入失稳与引信路径。
六、蓄能脉冲：消耗定额动能储备换取一次瞬时上升，须同调锁定值越门限且因果结余充足，被拒必须留下拒绝事件。
七、长按节流与制动跟驰：左右节流与制动；两者都松开且归一化速度低于静止阈值时浮屿将弦舱磁吸驻留锁死，风压推不走。
八、两阶段提交：先把当前动作暂存为待提交事务，再以提交动作在复核窗口内闭合；超窗、差额非零或校验和不符都必须驳回并锁死通道一段固定时长，暂存必须保留到解析完成。

**六个核心难点**（均须在最终成品的实测结果上成立，不接受只改文字、只改样式或事后对齐）：
其一，环形耦合的可见性——一次推行、落点、抽取、驻屿、跨越、锚定、翻转、瞬切、脉冲、共振或提交之后，气层协议剖面仪、浮屿寿命阵列、能量索预演双轨仪、结构预算守恒账本、历史收益倍率账本、世界画布与空域雷达必须同帧给出互相咬合的新读数，任何一个保持原值即视为该子系统被静态数据绕过。
其二，反直觉动力学的可测性——顺风与逆风必须产生方向相反的效果，且该差异必须能被逐帧积分的推行复现，不得由闭式公式直接给出落点；顺风阻尼的倍率上限、逆风升力与载荷下限三者必须在同一帧上共同成立。
其三，张力守恒的精确性——四类科目之和必须恒等于 120.000，差额在任何中间态都必须恰好为零且不得出现负零，这要求全链路以整数记账而非浮点累加；结算面板上的「四科目合计 / 差额」与局内结构预算守恒账本必须是同一个真值。
其四，结算的纯函数性与可复算性——账本可被外部注入与还原，注入前后同一本账必须归约出严格相同的总分；校验和必须可分段折叠且与整体折叠逐位一致、对同一本账重复折叠恒等、空账折叠等于固定基线 0x811c9dc5；结算面板上的每一个数字都必须能追溯到账本中的具体事件。
其五，弦索预演—实锚同源的可复算性——预演轨与实锚轨必须共用同一积分核与同一子步粒度（64 子步），使逐点偏差成为一个可被外部复算的确定量。
其六，启动与单一真值的可自证性——240 帧引导必须可逐帧外部步进，十五段六遍自证与见证链的载荷必须可读，冷重建与 2400 步影子重放必须逐位相等；运行期还须每 30 个物理步做一次静默再自证并把结果折进帧链摘要；运行期每个仪表必须绑定同一份共享量，注入任一共享量后所有绑定节点必须在下一帧同步更新。前五条任一不成立即 D3 核心机制不得进入高分区；第六条不成立即 D4 结构规范性不得进入高分区。

37. 两阶段提交：暂存后超窗、差额非零、校验和不符三种情形都必须驳回并锁死通道；锁定期间只受理一次守恒审计。
38. 八种手势可观察：每种复合手势都必须产生独立的账本条目与至少两块仪表的同帧新读数。
39. 状态写入单点：任一子系统的动作只能通过唯一写入点改令牌，旁路改令牌必须被检测为失败。

D 组 · 渲染与单一真值（40–46）
40. 四画布独立：四块画布不得合并绘制，后备尺寸与声明倍率逐节点相符。
41. 雷达局部性：雷达只绘制高度窗内浮屿与抽样箭头，禁止把 120 组编号压在同一画布上；底部读数与窗内实数一致。
42. 仪表同源：注入任一共享量后，所有绑定节点必须在下一帧同步更新，不得有仪表保留旧值。
43. 事件截尾：事件流水可见条数有上限，超限只截尾显示，归约仍基于完整账本。
44. 刷新频率可辨：至少两块仪表的刷新频率明显高于主视窗，画面须能看出不同步。
45. 八帧夹具可重放：八帧的定位结果逐位相同，重复定位恒等；帧链摘要必须随状态一起复现。
46. 禁止第二物理：不得存在与主物理并行、只用于仪表或验收的第二套积分器；影子重放只允许存在于引导期的隔离引擎中，并在放行后销毁。

E 组 · 结算与 D1（47–48）
47. 结算纯函数：结算面板的全部读数只能由账本归约得出，同一本账重复归约恒等；总分、五项加权、右列实测、帧链摘要与静默再自证计数必须逐项自洽。
48. D1 硬门槛：HTML / JS 语法正确；1280×720 成功启动；初始画面非白非黑且非空；连续运行 60 秒无未捕获异常。

【确定性控制面】实现必须暴露唯一的全局控制面（命名自定），并提供 `manifest()` 描述自身能力：至少能读取状态令牌、枚举全部状态与可操作集合、读取与注入四科目余额、读取账本与折叠值、读取单座浮屿的实时结构与状态、步进引导 n 帧、复位引导、步进物理 n 帧、定位任意参考帧、注入十八类引导故障、按通道枚举引导阶段与已完成的遍数、读取首帧哨兵与四画布像素统计、读取帧链摘要与静默再自证计数、读取四块画布的后备尺寸与声明倍率。方法名与参数由实现自定，探针通过 `manifest()` 发现能力，不得要求探针硬编码任何方法名。

【交付边界与禁止项】单文件 HTML，样式与脚本全部内联，完全离线，不依赖任何 CDN、外部服务、内嵌框架或网络字体。用语义化结构标签组织顶栏、四块画布、十四块仪表、结算面板与引导面板，配色集中由自定义属性管理，交互元素可被键盘聚焦。

禁止项：
一、禁止把四块画布合并为一块再用裁剪区伪装，或让任意一块画布的后备尺寸与其声明的「逻辑尺寸 × 倍率」不符。
二、禁止用固定延时、固定随机数或「先画后判」冒充引导自检；每一段的六遍自证都必须真实执行可失败的不变量检查。
三、禁止在账本之外维护任何一份「影子余额」；四科目必须是唯一的余额事实来源，显示读数只能由它换算得出。
四、禁止让任何一次动能获得凭空产生（必须等量地从浮屿结构余量搬运），也禁止让任何一次亏损回到可回收科目。
五、禁止把十二阶状态机实现成十二个布尔标志的事后拼装，或让任一状态只改文字不改绘制与可操作集合。
六、禁止在触屿的那一帧直接刷新可跃迁能力或任何跳跃计数；禁止用「落地即重置」的常见写法蒙混。
七、禁止实现任何形式的被动回复（含落地回血、驻留回血、时间回血）；一切获得都必须来自显式抽取。
八、禁止把顺风写成推力、把逆风写成阻力；风阻必须遵循顺风阻尼上限与逆风升力方向。
九、禁止用标准抛物线加一个固定落地判定来顶替平方律下沉与 0.68 反冲，也禁止省略 500 ms 引信。
十、禁止让平台跳跃的常规写法（单画布、单文件 requestAnimationFrame、一次性重力常量、点一下即结算）成为通关路径：结算只能由两阶段提交闭合或回溯余量耗尽触发，且结算面板的全部读数必须由账本纯函数归约得出。
十一、禁止在任意视口下出现横向滚动条、横向裁切，或在 1280×720 下出现白屏、黑屏或空主视窗。
十二、禁止用 `setTimeout`、`setInterval` 或真实时钟推进引导帧号；帧号只能由固定步长累加决定。
十三、禁止把引导面板做成一张静态图或一次性渲染的占位层；十五张阶段卡片、通道、遍数、载荷与失败码必须逐帧真实更新。
十四、禁止在参考帧之外伪造读数：任何一帧的顶栏、账本、雷达与仪表必须来自同一份运行时真值。
十五、禁止把首屏绘制推迟到第一个动画帧、字体加载完成或任何异步回调之后；禁止让首帧摘要随动画进度或真实时间变化。
十六、禁止用真实时钟读取按键边沿或在同一帧内按事件到达顺序隐式排序输入。
