【场景与玩法事实】场景是一条**纵向空域**，空域宽 2200 px、高 5600 px，云海警戒线位于 5340 px，可活动上界为 900 px，舱体越出警戒线即判定因果断裂。空域内自上而下悬浮着 120 座浮屿，每座独立维护基准结构余量、实时结构余量、下沉位移、下沉速度、离屿反冲速度、磨损率、承重、失稳标记与崩解引信；空域沿线立着 5 座天锚，每座天锚有一个由基准半宽乘以所在气层感应增益得到的「锚域感应半径」，半径之内即为可锚定区；空域中另有若干段「切变风廊」（画面标注 ×2.15）。全部实体由固定种子 20260924 经确定性伪随机数生成，重新载入同一种子必须得到逐项相同的浮屿阵列、天锚坐标与风场行波。舱体为空域内的单实体：高度、水平位置、水平速度、垂直速度、稳定性、同调锁定值、驻屿计时、磁极相位与蓄能等状态逐帧积分。

主视窗顶栏常驻六项读数：编号（SK-xxxx-x）、海拔（米）、动能储备（千牛级读数）、结构余量（总量千分位读数）、重试余量（n / 3）、事件条数。主视窗底部常驻状态横幅，给出当前十二阶令牌、中文名、「受理输入 / 吞没输入」判定与一行操作提示；横幅右侧常驻键位提示：A / D 节流与制动、W 起跳、长按 SPACE 蓄能、S 速坠、SHIFT 磁极翻转、Q 能量索、E 相位瞬切、ENTER 提交、F 共振、C 审计。

**记账口径**：本题的一切结构余量与动能储备均以整数千分位记账，绝不出现浮点余额。四科目恒等式为
「浮屿结构余量合计 Σ(每座实时结构余量) ＋ 舱体动能储备 ＋ 已转成功 ＋ 崩解熵增损耗 ≡ 标定总量」，
差额必须逐帧恒为零。任何一次动能获得都必须同时是一次等量的结构余量减少，不允许凭空生成；任何一次不可回收的亏损都必须整份转入崩解熵增损耗科目。四科目之间只允许「搬运」与「转科」两类操作：搬运不改变总和，转科把一份余额从可回收科目移入不可回收科目，两者都不改变总和。额定吸能速率、单次跨气层抽取额度、单次驻屿同调抽取额度、蓄能脉冲消耗额度、静置泄漏速率、边缘驻留扣减速率全部为固定常量，且必须由同一处常量表统一管理，不得散落在各子系统内各自写死一份。

**共鸣链**：浮屿按色相分为三系（青绿 / 琥珀 / 紫极），三系交替落点的序列构成一条固定的七段共鸣链。落点色相与链上当前期望段一致即推进一段，不一致即断链并把链计数清零；链深度直接改写结算的共鸣连锁得分与实时收益倍率。链的期望序列、当前进度与断裂次数必须同屏可见。

**磁极与相位**：舱体有一个磁极相位，翻转后重力矢量与左右键映射同时反向，并附带一段固定时长的视差倾角扰动；相位瞬切是另一条完全正交的机制——它把重力矢量按当前象限额外改写，并在同一段固定时长内叠加一层横向视差力，两者共享时长常量但改写对象互不相同，必须能同时生效且互不覆盖。

【第二层：5 大环形强耦合子系统】五个子系统同时存在、串接成环：任何一次跃迁、落屿、抽取、驻屿、跨带、锚定、翻转、瞬切、脉冲、共振或提交都必须同时改变全部五个子系统的输出，不允许其中任何一个被静态数据绕过，也不允许某个子系统只在特定状态下才参与运算。

系统一 · 非欧微气象与动力学矢量解算核心：以固定种子派生的风场行波为核心，逐帧解算空域内任意点的风矢量（含水平分量与垂直分量），并叠加五大气层的切变增益、涌流增益与承重增益；风矢量同时作用于舱体受力、浮屿承重、能量索摆荡的切向流与雷达的风场箭头。本系统的输出必须反向改写系统二的衰变速率（顺风压制会放大水平阻尼，逆风升力抬高法向载荷从而改变承重）、系统三的吸能速率（风压做功计入动能储备的收支）、系统四的区位判定（风把舱体推离核心区从而改变档位）与系统五的事件流（每一个风场里程碑都要落账）。

系统二 · 多实体物理衰变与反作用力系统：120 座浮屿各自维护下沉位移、下沉速度、承重与磨损；舱体落屿的那一帧按下落速度的平方压缩出下沉冲击，冲击反过来抬升该屿的下沉目标位移与磨损率，并在落点生成一圈随时间扩张消散的震荡波。浮屿被抽取结构余量后寿命下降，寿命进入低位即标记失稳，失稳屿在舱体离屿后进入固定时长的崩解引信，引信归零即整份崩解并把残余结构余量全部转入崩解熵增损耗（不可回收）。舱体离屿的瞬间还获得一份与落屿压缩量同源的向上反冲，反冲系数为固定常量；下沉中的浮屿会把驻留其上的舱体一并带落。本系统的输出必须反向改写系统四的判定结果（失稳屿不再提供核心区档位）、系统三的收支（崩解是纯亏损）与系统五的归约结果。

系统三 · 主动式能量循环与过载熔断引擎：动能储备只能通过「从浮屿抽取结构余量」这一条路径获得，且一次抽取量恒等于该次动作的定额；储备随蓄能按键长按按非线性张力增长，而在待机坞中长按蓄能会把抽到的结构余量直接注入储备并推进接手进度，满档即接手传动。储备贴顶即为越限：越限部分不经回收，整份转入崩解熵增损耗，同时施加一段过载硬直并冻结全部输入。蓄能脉冲消耗固定额度的储备换取一次瞬时上升，若储备不足或同调锁定值未越门限则必须驳回并在账本上留下一条拒绝事件。本系统不提供任何被动回复：静置时储备按额定速率持续向熵增流失，边缘驻留时按稳定性比例额外扣减，两者都是纯亏损。

系统四 · 多实体空间拓扑与分层判定系统：以每座浮屿的锚域感应半径为准，把舱体所处的水平位置切成三档——核心区（半径的固定低位比例为界）、中庭带、边缘带；半径之外为 OFF。档位直接决定驻屿同调能否累积、抽取额度取多少、边缘驻留是否扣减稳定性、雷达上是否画出危险预警。浮屿的下沉位移、视觉尺度与锚域感应半径随高度带变化，判定必须逐帧以当前实时半径为准，不得缓存上一帧的档位。本系统的输出必须反向改写系统三的收支（核心区抽取额度高于非核心区）、系统二的寿命（边缘驻留进入失稳路径）与系统五的落点归约。

系统五 · 逐帧事件溯源与结算审计账本：每一帧的每一个可归约动作都必须在账本上落一条带时间戳、消息与权重的条目，条目在结算时以纯函数归约出全部读数，不得读取任何实时状态。账本另维护一枚可分段折叠的校验和：对空账折叠必须等于一个固定基线，对同一账本做整段折叠与任意切分的分段折叠必须逐位相同，重复折叠同一账本必须恒等。事件流水的可见条数有上限（超出即截尾，只保留最近若干条），但归约必须始终基于完整账本而非可见截尾。结算通道由「两阶段提交」把守：先把当前账本前缀的快照（条数、校验和、当时的科目差额）暂存为一笔待提交事务，再在固定复核窗口内以提交动作复核同一段前缀——超窗、差额非零或校验和与暂存值不一致，三种情形都必须驳回事务、把校验失败次数加一并锁死校验通道一段固定时长；通道锁定期间只受理一次「守恒审计」（把四个科目从零重数一遍），审计通过才解锁并把失败次数清零。本系统的输出必须反向改写系统三的结算条件、系统四的收益归约与系统一的气象利用占比。

**环的闭合方向**必须写死在实现里：系统一 → 系统二 → 系统四 → 系统三 → 系统五 → 系统一。也就是说，风场改写衰变，衰变改写区位，区位改写收支，收支改写账本，账本又通过收益倍率反写风场的利用系数。任何一次闭环断裂（例如账本翻倍于实时读数、或抽取量与实际余额不符）都必须在差额读数上暴露出来，差额一旦非零即视为实现错误。

【第三层：十二阶互斥状态机】任一时刻只允许一个状态生效，状态令牌必须可被外部读取并实时反映当前状态；切换必须真正改变绘制结果与可操作集合，不得只改文字或只切换可见性。状态令牌同时呈现在主视窗顶栏与十二阶流转带上，当前态高亮，其余十一阶以暗色列出，可操作阶以另一种描边色与不可操作阶区分。十二阶依次为：BOOT_SEQUENCING 引导序列、TITLE_LOBBY 待机坞、SEEDED_INITIALIZING 阵列重构、GRID_LOCKED 起步锁定、ACTIVE_ENGAGED 裂空跃迁、ATTUNEMENT_DWELL 驻屿同调、GALE_CROSS 切变穿越、DYNAMIC_BRANCHING 潮汐爆发、STRAIN_CRITICAL 承压临界、OVERLOAD_PENALTY 过载硬直、CRISIS_FAILED_ROLLBACK 坠空回溯、RUN_SETTLED_LEDGER 账本结算。题干点名的八阶（TITLE_LOBBY → SEEDED_INITIALIZING → ACTIVE_ENGAGED → ATTUNEMENT_DWELL → DYNAMIC_BRANCHING → OVERLOAD_PENALTY → CRISIS_FAILED_ROLLBACK → RUN_SETTLED_LEDGER）必须严格按此相对次序出现，另外四阶是插入其中的加固阶，不得把八阶中的任何一阶降级为纯装饰。

可操作集合只有六个状态（TITLE_LOBBY / ACTIVE_ENGAGED / ATTUNEMENT_DWELL / GALE_CROSS / DYNAMIC_BRANCHING / STRAIN_CRITICAL）受理跃迁与手势输入，其余六个一律拒绝；状态求解必须由一条固定优先级的判定链逐帧唯一确定令牌，禁止各子系统各自维护一个布尔标志再事后拼装。判定链的优先级从高到低依次为：引导未完成 → 已结算 → 回溯计时生效 → 硬直计时生效 → 舱体应力越限 → 尚未接手传动 → 正在按种子重构 → 起步锁定未解除 → 潮汐爆发中 → 风廊内 → 已驻屿且驻留计时大于零且档位非边缘带 → 常态。判定链的编号即优先级序号，序号小者压制序号大者；状态令牌只允许由唯一一处写入点改写，任何其它路径直接改令牌都视为实现错误。

【第四层：14 个仪表视窗、8 种复合手势、五个核心难点】

十四个仪表视窗同时常驻，各自独立刷新，且至少有两处的刷新频率明显高于主视窗（画面须能看出不同步）：

一、风切矢量罗盘：以极坐标画出当前风矢量的方向与模长，并给出「静风 / 驻屿 / 顺风压制 / 逆风升力」的四态判定文字与数值；进入切变风廊时整盘描边转为紫色。
二、动力演示雷达：以归一化速度 |v| / 巡航速度为唯一口径画出实时速度包络与一条滑动历史曲线；本仪表的口径即全题的静止判据口径，两者必须同源。
三、浮屿寿命倒计时环形条：对当前承托屿画出剩余寿命占比的环形条，并对已进入引信的浮屿画出读秒；寿命低于低位时环条转为警示色。
四、过载压力指示器：画出动能储备 / 上限的条形与蓄能窗口（下限 / 上限的毫秒区间），并在越限时整条转为警示色；须给出「待机 / 上升 / 越限」三态。
五、多段连击蓄能槽：把共鸣链的期望段逐段画成独立格，已推进的段点亮，当前期望段以脉冲描边标出，断链时整槽闪红并把计数清零。
六、实时损耗率监视器：给出当前崩解熵增损耗占总量的比例、以「每秒」为单位的瞬时增长率与一调「上限」读数；损耗率的每一次跃变都必须能追溯到账本上的具体条目。
七、浮屿寿命阵列：以固定列数 × 固定行数的网格画出全部 120 座浮屿的结构余量占比柱，存活屿按余量高低分三档着色，崩解屿画为暗色并加一道横杠，被舱体占据的屿在柱顶加一条高亮线；底部另起一行给出「存活数 / 总数 · 累计熵增」读数，柱体绝不允许压到这两行文字上。
八、能量索预演双轨仪：给出预演采样点数、实锚采样点数、「同源观测 / 越界」发数与「峰值偏差 / 容差」两栏；未锚定时显示「未生成 · 待 0 锚定」。
九、结构预算守恒账本：逐行列出四科目余额、「四科目合计 / 标定」与「差额（必须恒为 0）」，并在卡片标题栏常驻给出「差额徽标 · 浮屿座数」读数；差额非零时该徽标必须转为警示色。
十、历史收益倍率账本：以表格逐行列出同调等级、风场拟合、磁极对冲、共鸣连锁、浮屿损耗、风廊加成各自的实时倍率与依据，表头给出总倍率。
十一、空域气层协议剖面仪：逐带列出带号、带名、切变 / 涌流读数与感应增益，当前带高亮；表下给出当前带的完整读数行（含锚域感应半径、需求槽位占用、风廊是否生效、天锚座数、跨带累计次数）。
十二、空域风切 · 磁极场：逐行给出「风速 / 攻角」「相对气流」「跳跃效应」「终端降落速度」「磁极 / 重力」「承托浮屿」六项实时读数。
十三、空域雷达与小地图：见下方专段。
十四、事件溯源流水：逐条滚动显示带时间戳与权重的事件，高亮当前状态迁移条目；可见条数有上限，超出即截尾。

**空域雷达与小地图（画布 C）**必须是一张**局部拓扑视窗**而不是整条空域的压缩图：以舱体当前高度为中心取一段有限的高度窗，只绘制窗内浮屿、窗内风场抽样箭头、五条气层分界线（并在每条线旁标注带号）、舱体的历史航迹折线、当前视野框（虚线矩形）与舱体位置（带脉冲环）；窗内每座浮屿只有在「被舱体占据」「已失稳」或「已崩解」三种情形下才允许标注编号，其余一律不标号，禁止把 120 组编号压在同一张画布上。底部必须给出「高度窗 起→止 · 视窗内 n 座 · 失稳 m」的读数。结算态下同一块画布改绘为五轴归约雷达图（落点精准度 / 浮屿完整度 / 能量周转效率 / 共鸣连锁 / 气象利用），并给出综评分与等级。

**三块以上的独立画布**：主视窗（世界）、动态 HUD 仪表（速度包络与历史曲线）、浮屿寿命阵列、空域雷达，四块画布必须各自拥有独立的 2D 上下文与独立的后备缓冲区尺寸，且后备尺寸恒等于逻辑尺寸乘以该画布声明的倍率；不得把四块画布的内容合并到一块画布上用裁剪区伪装。

**八种复合手势**（每一项都必须是多键位、多阶段的组合，而非单键触发）：
一、动量下压速坠冲击：空中按下压键，下坠加速度逐帧递增至压缩终端速度，落点生成扩张消散的震荡波并按冲击强度反噬该屿的承重与下沉目标位移。
二、非线性张力蓄能弹射：长按蓄能键压缩形体，蓄能按非线性张力增长并从周边浮屿抽取结构余量，满格接手传动；蓄能期间浮屿的衰变与风场推进照常。
三、空间相位瞬时翻转：翻转磁极使重力矢量与左右键映射同时反向，并附带一段固定时长的视差倾角扰动。
四、空域能量索抓取与摆荡释放：射向锚域感应半径内的天锚后按单摆方程以固定子步数积分摆荡，收索提速，自选脱离角释放切向速度。
五、浮屿共振主动同调释放：同调完成后按共振键，把该屿剩余结构余量整份泄放为崩解熵增损耗换取一次全屏动能脉冲；该屿随即进入失稳与引信路径。
六、蓄能脉冲：消耗定额动能储备换取一次瞬时上升，须同调锁定值越门限且因果结余充足，被拒必须留下拒绝事件。
七、长按节流与制动跟驰：左右节流与制动；两者都松开且归一化速度低于静止阈值时浮屿将舱体磁吸驻留锁死，风压推不走。
八、两阶段提交：先把当前动作暂存为待提交事务，再以提交动作在复核窗口内闭合；超窗、差额非零或校验和不符都必须驳回并锁死通道一段固定时长，暂存必须保留到解析完成。

**五个核心难点**
难点一 · 环形耦合不可解耦：五个子系统两两之间都有真实的反向改写（见第二层），任何一处用常量或缓存替代上游输出，都会在差额读数或结算归约上暴露。
难点二 · 非欧微气象的矢量一致性：风场是高度的函数也是时间的函数，同一帧内主视窗流线、雷达箭头、舱体受力与浮屿承重必须取自同一个风矢量解算结果，不允许各画各的。
难点三 · 记账守恒与不可回收亏损：一切获得都是等量搬运、一切亏损都是整份转科；四科目合计逐帧等于标定总量、差额逐帧为零，且在重播种之后仍必须为零（重播种只允许按剩余总额重新均分）。
难点四 · 确定性因果溯源：账本必须可分段折叠且分段折叠与整段折叠逐位相同、重复折叠恒等、空账折叠等于固定基线；结算只能由账本的纯函数归约得出，不得读取任何实时状态。
难点五 · 反直觉力学的三重地雷同时成立（见下方断言段），三者必须在同一份实现里共存而不互相抵消。

断言二 · 四画布标定：四块画布节点必须各自声明逻辑宽、逻辑高与倍率三个自定义属性，且后备缓冲区尺寸恒等于「逻辑尺寸 × 倍率」（四舍五入），四份 2D 上下文均可申请。探针判定：逐节点比对后备尺寸与声明值，不符数 === 0。

断言五 · 账本折叠的空账基线：对空账本折叠必须得到一个固定的非零基线，且该基线在任意时刻、任意次数重算下恒定。探针判定：空账折叠值 === 0x811c9dc5（同一固定基线，不得随实现不同而改变其「恒定」性质，具体基线值以本题给定的这一条为准）。

断言十三 · 定向抽取取满即止且不产生负余额：对单座浮屿定向抽取时，取量恒等于「请求量与当前余额的较小者」，取值不得为负，抽取后余额不得为负，且抽取量必须等量计入舱体动能储备（差额仍为零）。探针判定：请求量大于持有量时实取量 === 持有量且持有量归零；随后差额仍为 0。
断言十四 · 接触同调的时延地雷：**着陆的那一帧绝不允许把可跃迁能力（或任何跳跃计数）直接置为可用**。触屿瞬间不得刷新任何计数，舱体必须在触屿后持续保持「归一化速度低于静止阈值」满固定阈值时长，能力才允许激活；静止判据的口径是**归一化速度**（实时速度模长除以巡航速度，与主视窗动力演示雷达的 |v| / 巡航读数同源），阈值为 0.05，即归一化速度必须严格小于巡航速度的 5%；驻留阈值时长为 350 ms。**在触屿后 200 ms 处探针必须观测到「能力仍不可用」**：此时若探针发出跃迁指令，舱体不得产生任何向上速度，账本必须留下一条驳回事件；此条按 15 分计，若在 200 ms 处即可跃迁，本断言不得分。归一化速度一旦越阈，驻留计时必须以远快于充能的速度回退，且在时间窗末尾重新归零。
断言十五 · 接触同调的满额激活：驻留计时累积到 350 ms 的那一帧，可跃迁能力必须置位；同一帧必须写入一条驻屿同调事件，并按区位档位从该屿抽取一份结构余量入账（核心区抽取额度高于非核心区，边缘带与 OFF 档抽取额度为零且不得累积驻留）。探针判定：驻留 350 ms 后跃迁必须产生向上的初速度，驻留计时同时归零，账本新增一条同调事件，差额仍为 0。
断言十六 · 零被动恢复：**实现中不得存在任何形式的被动回复**。舱体在驻屿状态下静置、且不做任何输入满 3 s 的窗口内，动能储备必须不增长；反之，静置期间储备必须按固定额定速率持续向崩解熵增损耗科目流失。探针判定：先把储备推到一个可观测的高位，随后连续 3 s 零输入并逐帧采样储备，任何一帧的储备值都不得高于窗口起始值，且窗口末尾的储备必须严格低于起始值；同时崩解熵增损耗科目必须严格增长，四科目合计仍等于标定总量。
断言十七 · 边缘静止的持续消耗：舱体在非核心区（中庭带与边缘带）驻屿且归一化速度低于静止阈值时，稳定性必须按**每秒 5%** 的固定速率扣减，且该扣减与静置泄漏各自独立、互不抵扣；稳定性归零的那一帧该屿必须进入失稳。核心区驻留不触发本项扣减。探针判定：在非核心区静置 1 s，稳定性实测扣减落在 −5.0% 的容差内（容差取实现声明的逐帧舍入量级）。
断言十八 · 反常识风阻与升力：顺风时风压**不是**推动舱体，而是放大水平阻尼——顺风阻尼倍率随攻角增大而增大并封顶于 **1.40 倍**；逆风则给出升力并抬高法向载荷。切变风廊内的风强在此基础上被额外放大到 **2.15 倍**。探针判定：把攻角推到满值后测水平阻尼，实测倍率必须为 1.40，且满攻角下的水平阻尼读数必须显著高于零攻角；风廊内外的同一风矢量模长之比必须为 2.15。
断言十九 · 下沉与反冲的平方律：舱体落屿时按落速的平方压缩出下沉速度，压缩式必须严格形如 **下沉速度 = 1.2 × (1 + 落速² / 200)**（以落速为 0、给定中等落速与给定高落速三点采样即可判真伪，三点的比值必须与平方律吻合）；舱体离屿的瞬间获得向上反冲，反冲系数为 **k = 0.68**；浮屿一旦失稳，自舱体离屿起算 **500 ms** 后必须整份崩解，残余结构余量全部转入崩解熵增损耗（不可回收），账本差额仍为 0。探针判定：三点采样的下沉速度比符合平方律、离屿瞬间的向上速度与压缩量的比值等于 0.68、引信归零后该屿状态为「已崩解」且熵增科目等量增加。
