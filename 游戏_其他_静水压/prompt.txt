一、五个环形耦合子系统（≥5，必须环环相扣，禁止任何一个是独立的）

- **子系统 1 · 非欧微气象与动力学矢量解算核心**：洋流不是一个常数，而是多层内波模态叠加出来的矢量场，振幅、波数、频率与相位都随层带下标变化；密度跃层处存在速度剪切，使跃层上下的垂向流向反号。潜航体被所在层的洋流平流带走，而**推进器的有效出力随相对流向折减**：顺流时水阻被非线性放大（图上读数为"顺流 · 阻尼 ×1.40"），迎流时迎角反而产生一个向上的升力矢量（图上读数为"迎流 · 升力矢量"）；横向机动必须借层间流向差"摆渡"。洋流矢量罗盘必须实时给出模值与顺/逆/横三档判定。
- **子系统 2 · 多实体物理衰变与反作用力系统**：每一段浮屿都有独立的耐久、下沉位移与回弹速度；被冲击后按下沉位移与冲击速度的关系下沉，而**下沉量对冲击速度是饱和型非线性**（速度越大越接近上限，不会线性发散）。潜航体离开某一段的瞬间，那一段以小于 1 的固定回弹系数朝反方向弹起，此后再经过一段固定引信时间碎裂为不可站立的虚空。受击的浮屿会波及邻格。这一切都必须逐帧积分，禁止"打一下掉一格血"式的离散扣减。
- **子系统 3 · 主动式能量循环与过载熔断引擎**：高压气、稳定性储备与动能**绝对禁止自然被动恢复**——只要没有主动手段在施加，这三项随时间只能持平或下降，绝不能上升。高压气只有两个来源：站上浮屿正中的精准同调核心区，或完成一次带足够切向速度的能量索摆荡释放。氧气只有在母船补给区那一层才能回充。稳定性储备只在核心区内增长，而**停在浮屿边缘则按每秒固定比例持续流失**（速率可从 img_003 仪表组的稳定性储备条标签读到）。结构疲劳只在压碎层暴露时累积，只有回到水面减压舱才修复。**过载熔断**是这套循环的安全阀：气囊容积越过结构上限即强制排气、扣分并进入一段硬直，且熔断有独立计数进入结算。
- **子系统 4 · 多实体空间拓扑与分层判定系统**：每一段浮屿在几何上被切成三层——正中的**核心受击点**、两侧的**擦弹边缘**、以及下方的**动量吸收域**。三层的判定条件互不相同：站在核心带上才计同调；停在边缘上不但不计同调还要按秒扣稳定性；而动量吸收域决定速坠冲击的传播半径与衰减。热液喷口的判定更严：只有正中那条窄带算数，站在喷口所在格但偏出窄带，既拿不到同调、又要按边缘规则扣稳定性——所以喷口格本身必须是一个**陷阱格**。速坠冲击的伤害与半径都由触底时的下向速度决定，越过某个速度门才能击穿铁甲蟹的甲壳，否则只算一次无效碰撞。
- **子系统 5 · 逐帧事件溯源与结算审计账本**：每一件有意义的事都以（帧号、时刻、事件类型、带符号数额、人类可读说明）五元组记入账本，账本只增不删，界面上滚动显示最近若干条。结算面板上的每一个数字都必须由这本账**回溯聚合**得到，写死数值直接判零。账本同时是收益倍率的来源：连续击杀累积连击段数，段数越高同一事件入账的额度越高，而连击有一段归零倒计时，长时间没有新事件即整段清零。

环形闭环（必须真的闭环，不能只是并列）：洋流矢量 → 横向与垂向姿态 → 能否停在喷口核心带 → 同调充盈 → 高压气与稳定性 → 能否完成蓄能弹射与同调脉冲 → 能否清掉压到水面的深渊生物 → 脐带余量 → 是否触发危机分支 → 是否被迫进入过载熔断 → 熔断硬直期间浮屿被啃碎 → 可站立面变少 → 精准同调的点位变少 → 回到第一步。任何一环断开，整局都会退化成一个可以靠单一手段刷分的玩法。

| ATTUNEMENT_DWELL | 落在喷口精准核心带上并进入低速驻留 | 已解算完毕且未处于危机、未熔断 | ACTIVE_ENGAGED | 同调充盈推进、高压气与稳定性开始增长、喷口谐振环外扩；速度越界则进度打回 |
| DYNAMIC_BRANCHING | 结构疲劳越限 或 脐带余量跌破警戒线 | 已解算完毕且未熔断、未回滚 | ACTIVE_ENGAGED / CRISIS_FAILED_ROLLBACK | 主视窗红色暗角按危机度增亮；深渊王入场；损耗率监视器转警示 |

状态解析必须是**优先级抢占**的：同一帧内多个条件同时成立时，只能有一个胜出，且优先级次序固定（回滚 > 结算 > 熔断 > 危机 > 同调 > 主循环 > 解算 > 标题），不得出现两个状态同时为真。禁止用全局布尔量拼状态。

三、多画布独立渲染（≥3 块物理独立画布 + ≥5 个独立仪表模块）

- **画布 A · 主视窗剖面**：五层水色与层界虚纹、棋盘与浮屿（含耐久、引信、碎裂虚空三种外观）、喷口羽流与核心带、出怪舱口、母船与脐带、深渊生物、潜航体、深度刻度，以及分状态叠层（逐格显影扫描 / 喷口谐振环 / 危机暗角 / 过载压环 / 回溯暗幕）。主视窗必须能自己把当前状态画出来，不能只靠顶栏那行文字。
- **画布 B · 动态仪表阵列**：至少五个互相独立的仪表模块——① **洋流矢量罗盘**（模值读数 + 顺/迎/横三档标签 + 层带剪切线）② **深度剖面规**（五层色带、深度游标、深度大字、所在层名、静水压、气囊容积、净浮力）③ **资源条组**（高压气 / 氧气 / 稳定性储备 / 结构疲劳 / 压载水量 / 气囊容积，每条都带名与值，气囊那一条画的是容积而非含气量）④ **实时损耗率监视器**（气·氧·疲·稳四路每秒增减率，正增益转警示色）⑤ **层带色标**（五行色块 + 密度 + 透光率）。此外常驻六条手势键位提示。
- **画布 C · 声呐回波剖面**：以本艇为中心的水声剖面，层界处会折射出**镜像幻影回波**（暗目标），实回波画亮目标，两者必须能一眼分开；顶部另附一条脐带张力条。
- **画布 D · 环形计量**：七格浮屿环（剩余耐久 / 引信 / 重组三态）、同调充盈环、十二段连击蓄能槽（三段配色）、当前收益倍率、连击归零倒计时，以及底部统计带（速坠次数与峰值、相位翻转 / 蓄能弹射 / 能量索 / 过载四项计数）。
- **画布 E · 收益倍率账本**：逐帧事件滚动列表，每行给出帧号、时刻、事件名、带符号数额与说明；右上角常驻当前倍率。

四、复合高阶交互手势（≥5 种微操作，全部必须真实可玩、有明确手感，且都消耗有限资源）

1. **动量下压速坠冲击**：按住下压键使潜航体获得额外下向加速度并同时抽走气囊容积；触底瞬间按触底速度生成冲击波（半径与伤害随速度变化），速度越过门槛才能击穿铁甲蟹的甲壳。
2. **非线性张力蓄能弹射**：长按蓄能、松开发射。冲量对蓄能量是**超线性**的（指数大于 1，越接近满蓄能边际收益越大），蓄能期间持续抽走气囊容积；蓄能越满，发射瞬间越需要留出上浮余量。
3. **空间相位瞬时翻转**：一次瞬时位移，代价是固定的一笔高压气，并让主视窗进入一段以百毫秒计的视差倾角扰动窗口，期间画布边缘出现撕裂描边。这是躲避不可拦截的压力波的唯一手段之一。
4. **空域能量索抓取与摆荡释放**：在抓取半径内抓住格点，机身按单摆方程摆动（有阻尼），松手时按切向速度加权回补高压气——但只有切向速度越过下限才给气。这是高压气在远离喷口时的唯一补给途径，因此摆荡必须"荡起来"才有价值。
5. **浮屿共振主动同调释放**：在喷口核心带驻留满同调后释放一次脉冲，以固定半径造成伤害并可击穿铁甲蟹甲壳；释放后喷口进入一段冷却，冷却期间同调不可再蓄——**不允许靠连续点按刷取**。

另有基础操纵面（压载注/排、气囊注气/排气、横向推进、暂停/重开/返回）不计入上述五种复合手势。

五、反常识机制（必须真实生效，照常识惯性实现必然失败）

1. **接触同调时延**：触地**不等于**同调。落点必须先把速度压到近零并连续保持满一段以百毫秒计的窗口，同调才开始推进；触地瞬间的"落地即给"是错的，在窗口内提前松劲同样会把进度打回。若按"落地即蓄"，玩家可以在任意浮屿上无限刷资源。**这条的时延数值写在 img_001 标题层里，以图为准。**
2. **零被动恢复与静止消耗**：高压气、稳定性储备与动能**没有任何随时间自然回复的路径**。高压气只能来自喷口核心区的驻留或摆荡释放；稳定性储备只在核心区增长，而停在浮屿边缘则按每秒固定比例流失；动能越不动越少。因此"什么都不做地悬停"是纯亏损——若按"随时间慢慢回满"实现，整局资源约束会立刻失效。**边缘流失速率写在 img_003 仪表组的稳定性储备条标签上，以图为准。**
3. **反常识风阻与下沉反冲力学**：顺流时水阻被**非线性放大**（图上"顺流 · 阻尼 ×1.40"），迎流时迎角产生一个**向上的升力矢量**——也就是说顶着洋流上浮反而更省。浮屿的下沉位移对冲击速度是**饱和型**的：轻撞几乎不动，重撞迅速逼近上限，但永远不会超过它。潜航体离开某一段浮屿的瞬间，那一段以**小于 1 的固定回弹系数**朝反方向弹起，此后经过一段固定引信时间碎裂为不可站立的虚空。若按"平台静止不动"或"线性下沉"实现，速坠冲击的收益与风险关系会完全反过来。**引信时长写在 img_001 标题层与 img_003 环形计量的"引信"标注里，以图为准。**

六、红线（任一违反，本题直接判零）

- 交付单个 .html 文件，CSS 与 JS 全部内联，双击离线可运行；**不得**出现任何外部脚本、样式表、字体、图片、音频或网络资源。所有图像必须由 Canvas 代码程序化生成，所有音效必须由 Web Audio API 纯代码合成。
- **不得**使用 iframe、srcdoc、Base64 贴图，**不得**使用任何第三方游戏框架或物理引擎。
- 物理必须由逐帧速度与加速度积分产生，固定步长推进；浮力、压载、气囊容积、洋流、下沉与回弹一律按步长累加。**不得**用现成的具名缓动函数替代物理解算。
- **不得**在全屏单画布内完成全部渲染；至少 3 块物理独立画布节点。
- 所有随机量必须由固定种子驱动的确定性伪随机数发生器产生，同种子同输入逐帧可复现；**禁止**使用系统随机源。
- **禁止**弹窗类阻塞接口与向文档流写入内容；不得出现占位文本、未实现的空壳面板或与真实数据不符的读数。
- 页面启动与持续运行期间，控制台不得出现任何未捕获异常、脚本错误或资源加载失败。
