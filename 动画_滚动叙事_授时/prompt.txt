第 1 层　任务背景与系统定位（核心约束）
────────────────────────────────────────────────────────────

你要在一个单文件 HTML 里复刻一座十七世纪天文钟的滚动叙事长卷。

整座钟只有一条时间轴：一条纵向的虚拟滚动轴。它不是一个可以真正滚动的长页面——
舞台固定钉在 1280×720 的视口里，页面本身不可滚动、横向不可溢出。这条轴由滚轮、
方向键与翻页键与首尾键、以及底部一条进度条共同驱动；进度条既能拖拽粗定位，
也能被键盘接管。除这条轴之外，不存在任何自动产生的时间：停手即停摆。

轴上的位置即「指令相位」。机构并不瞬移到指令相位，而是被一套真实的跟踪动力学拖着
走：可用扭矩减去粘性阻尼力矩，再减去一层周期性的负载扰动，得到净扭矩；净扭矩除以
等效转动惯量给出角加速度，角加速度积分出角速度，角速度积分出机构相位。因此角速度
不是任何常数：它由瞬时扭矩逐帧解出，并在整个周期里持续脉动。机构相位永远在追指令
相位，两者的差值就是这套叙事的张力来源。

相位从 0 走到 1，就是一座钟走过十二个时辰。叙事被切成五段长度互不相等的章节——
起弦、传动、擒纵、报时、归位——章节边界不是等距切分，而是同时充当状态机的观测
断面。滚动轴到底时相位必须严格回到 1（探针按小数点后九位比对），不得靠末端硬夹、
不得在临界处跳变。

世界时钟按固定步长推进，且渲染帧率与推演步长必须彻底解耦：一帧渲染可以消耗零个或
多个推演步。同一份驱动脚本重复执行两次，必须得到逐位一致的推演结果——齿位阵列、
齿位寿命、风向相位、涡旋生成位置全部由固定种子展开，禁止任何真随机源。

屏幕被切分为六块物理独立的画布，各自持有独立的 DOM 节点、独立的位图尺寸、独立的
2D 绘制上下文与独立的绘制入口函数，共享同一份内存物理状态，但不共用同一拍渲染：

　· 主视窗（十二时辰刻度环）——由内向外五层机构带：弦轴层 / 传动层 / 擒纵层 /
　　报时层 / 同调层。越靠外圈摩擦越低、对流剪率越强，因此「走哪一层」永远有代价。
　　环上布着一圈棘齿，其中十二枚是主承力齿，按子→亥的次序顺时针排布；只有踩在
　　主承力齿的核心区上才算「承力」，其余齿位可以站立，但既不传递扭矩也不给同调。
　　环内是四级互质轮系（擒纵轮 / 中间轮 / 报时大轮 / 太阳轮）、擒纵叉与限位钉、
　　报时凸轮与青铜钟，以及一层随磨损单向扩散的熵增尘粒场。
　· 顶栏仪表带——六个并排仪表。
　· 传动比账本与相位图（左上）。
　· 齿位寿命环与实时损耗率（左下）。
　· 对流矢量罗盘与时段（右上）。
　· 状态断面（右下）。

视觉语言：深色黄铜天文钟。暗底、铜金刻线、宝石红、极细的整数刻度。不许出现卡通、
扁平色块、圆角塑料感。所有数值必须等宽对齐，所有表盘必须来自真实物理量。

以下四项为强制扩增指标，缺一不可。

（一）五个环形强耦合子系统

系统由五个首尾相接的子系统构成，任何一个的中间量都不得写死，且必须能被逐帧观测到
它被另外几个子系统回灌：

　1. 非欧微气象与动力学矢量解算核心。钟房热对流是若干层内波模态的叠加，风向不是
　　 常量场：剪率让相邻半径处的风向局部反号，于是「顺流」与「逆流」沿刻度环交替
　　 出现，没有哪一段能一路顺到底。风只以「相对来流」的形式进入动力学，且符号是
　　 反的：顺流时阻尼被非线性放大（顺风反而更慢、推得更近），逆流迎角则产生升力
　　 （逆风反而更高、飞得更远）。风场必须按工况分层，三档工况的风场剪率与极速倍率
　　 两两可分。这条因果关系会被逐帧核对，不允许只是文案。
　2. 多实体物理衰变与反作用力系统。校时梭以一定速度砸在承力齿上时，齿位会下沉，
　　 下沉深度与冲击速度的平方正相关，下沉的齿位其核心区随之失效。同时梭子自身被
　　 反方向弹起，弹起速度与冲击速度成正比。被反复压沉的齿位寿命单向衰减，衰减到
　　 底的齿位不再传递扭矩，也不会自行恢复。
　3. 主动式能量循环与过载熔断引擎。发条势能是唯一的能量池，它只从「不对称功」中
　　 回补——逆流段的推进、跨章节的姿态修正、张力蓄能的定向释放，都属于不对称功；
　　 匀速顺流滑行不属于。过载判据看的是「操盘手拨得多快」（指令相位的变化速率），
　　 而不是机构自身的追赶速率：卡位窗冻结相位之后必然有一段追赶爆发，那是机构
　　 响应，不是越限操作。越限一旦连续成立，擒纵转入跟随、整段卡位被跨过、磨损
　　 加速累积、结构进入硬直。
　4. 多实体空间拓扑与分层判定系统。齿位、层带、涡旋、悬索锚塔、相位置换门与轴心
　　 本体共用一套分层坐标系，判定必须分层进行，禁止把所有实体拍平到同一个平面上
　　 做距离比较。结壳类涡旋带护甲，只被足够快的下压冲击波或同调脉冲贯穿；相位类
　　 涡旋不可拦截，只能靠相位翻转规避。
　5. 逐帧事件溯源与结算审计账本。账本条目是五元组——[帧号, 相位, 类别, 数值, 备注]，
　　 当局内每一次放行、卡位、报时、同调、压沉、碎裂、摆荡、脉冲、越限、失败都要
　　 落账，条目顺序即因果顺序。结算面板的每一格都必须由这本账重放复算出来，
　　 严禁写死任何展示数值。

（二）八阶互斥有限状态机（完整决策表）

禁止用若干布尔变量的组合去间接表达状态。必须是一张有抢占优先级的守卫表：自上而下
取首个命中者，兜底态排在表尾，任何时刻恰好有一个状态成立。状态名必须逐字使用下列
八个英文标识符，不得改名、不得增删。

| 状态名 | 触发源 | 前置守卫 | 目标状态 | 副作用 |
|---|---|---|---|---|
| TITLE_LOBBY | 冷启动或显式退回待机 | 本局尚未开始（唯一的非叙事态，只能被显式开局或显式退回改变） | 种子重构 | 机构静止，相位与势能停在初值，账本空载，叠层显示标题与局号 |
| SEEDED_INITIALIZING | 开局 | 自开局起的齿位阵列建成窗口内 | 主动运转 | 齿位阵列按固定种子逐格点亮，主视窗出现扫掠遮罩、未建成扇区压暗，寿命环与承力齿标记随建成进度推进 |
| ACTIVE_ENGAGED | 兜底（以上皆不命中） | 无条件 | 主动运转 | 擒纵逐臂放行、每转一圈在整圈处卡位一次，四级轮系按齿数反比传动，报时凸轮按相位落点敲钟 |
| ATTUNEMENT_DWELL | 梭子贴地并拉起锚定 | 贴地、锚定充能中、尚未完成同调，且不处于回溯读条期 | 主动运转 | 驻留环充能，损耗率显示为负值（这是稳定度唯一回补的窗口），充能满足时把跃迁余量由 0 置 1 |
| DYNAMIC_BRANCHING | 涡旋密度越过该工况的分支门限 | 分支区间是可持续多帧的区间，不是单帧脉冲 | 过载失稳硬直 | 罗盘与损耗率监视器转警示色，账本写入分支条目，分支区间内额外生成涡旋 |
| OVERLOAD_PENALTY | 指令速率连续越限 | 越限计数生效中（单帧尖峰不计） | 致命失败与因果回溯 | 擒纵仪表标注为跟随中，整段卡位被一步跨过并计入跳过计数，磨损加速累积，结构进入硬直窗 |
| CRISIS_FAILED_ROLLBACK | 稳定性储备或磨损熵越过致命线，或撞穿刻度环外缘 | 回溯读条进行中 | 相位归零·审计结算 | 相位按读条进度回退，涡旋清空，稳定性兜底到一个固定值，机构抖动，期间禁止一切位置突变 |
| RUN_SETTLED_LEDGER | 相位走满 1，或显式收束 | 本局已结算 | 待机就绪（仅在闭环档位下自动重开） | 打开结算卡：按账本重放六项量纲（存在主动锚定尝试时追加第七项落点精准），逐格列出并给出综合评分与评级 |

抢占优先级（越靠前越高，多条件同时成立时由这张表裁决）：
TITLE_LOBBY > RUN_SETTLED_LEDGER > CRISIS_FAILED_ROLLBACK > OVERLOAD_PENALTY >
DYNAMIC_BRANCHING > ATTUNEMENT_DWELL > SEEDED_INITIALIZING > ACTIVE_ENGAGED。
终局必须优先于回溯读条：结算之后推演早退、读条不再递减。

（三）多画布独立渲染与专业 HUD 架构

彻底封杀全屏单 Canvas 绘制。至少三块物理独立的画布节点，每块画布拥有独立的位图
尺寸与像素内容，且拥有各自独立的绘制入口函数——必须能在不触碰其余画布的前提下
单独重绘任一画布；用一个全局绘制函数顺序重画全部画布，不算多画布。
1024 至 2560 视口宽度下均不得出现横向溢出。

至少五个专业仪表视窗，各自的量纲、单位与刷新依据必须写在表盘上：

　1. 风切矢量罗盘——极坐标雷达，矢量长度取风压、方位取风向，轮廓在分支期与回溯期
　　 转警示色，并给出当前时段名。
　2. 浮屿寿命倒计时环形条——环形条，按齿位寿命与当前蓄能双环显示，寿命见底时转警示色。
　3. 多段连击蓄能槽——分段蓄能条，越限时整条转警示色并标注超限。
　4. 实时损耗率监视器——逐帧列出势能 / 恒定 / 结构三项损耗率及其正负号。
　5. 历史收益倍率账本——四级轮系的瞬时转角与齿数比误差，外加一条相位—速率相图轨迹。

（四）复合高阶交互操作手势（至少五种，每一种都必须产生物理后果而非仅仅改变观感）

　1. 动量下压速坠冲击——在空中主动下压，把竖直速度瞬间改写为向下的冲击速度；
　　 落点齿位的下沉深度由冲击速度的平方决定，梭子被反方向弹起。
　2. 非线性张力蓄能弹射——按住蓄力，蓄力量随时间非线性累积并同时消耗势能；
　　 松手时按蓄力量的幂次释放为切向冲量（幂指数大于 1，因此蓄得越久越划算，
　　 但势能代价是线性的）。
　3. 空间相位瞬时翻转（伴随约 300 ms 的视差倾角扰动）——瞬时翻转有效风向的符号，
　　 并在随后一段窗口内免疫风压；窗口内其余手势照常生效。翻转本身一次性扣除势能。
　4. 空域能量索抓取与摆荡释放——在悬索锚塔的量程内抓取，抓取后梭子按单摆方程摆荡，
　　 切向角速度由摆动幅度解出；释放时若切向角速度越过下限，按该角速度回补势能并
　　 落账，不足下限则只落一条失败账、不回补。
　5. 浮屿共振主动同调释放——只有在同调态才可释放，释放后驱散半径内的涡旋，
　　 每个涡旋转为积分并落账。
　6. 基础跃迁——只有在同调余量为 1 时才被接受，其余时刻一律拒绝。

────────────────────────────────────────────────────────────
第 3 层　行为因果回路与三条反直觉断言地雷
────────────────────────────────────────────────────────────

以下三条是硬断言，探针会逐帧核对。凡命中地雷，按 D3 核心机制分直接扣分。

地雷一　接触同调时延
落地不会立刻回满跃迁余量。梭子必须在支撑面上把横向速度压到近乎为零，并以
|v| < 0.05 持续停留 ≥ 350 ms 完成「能量同调」之后，跃迁余量才由 0 置为 1。
触地即作废同调——无论轻重，落地都要重新挣回这 350 ms。
探针的行为是：制造一次着陆，在 t = 200 ms 时发跳跃指令；若这次跳跃被成功执行，
判定为用「落点即二段跳」绕过了本雷，扣除 D3 核心机制 15 分。

地雷二　零被动恢复与静止消耗
不存在任何零输入的被动恢复。探针保持键盘零输入 3 秒，若能量池 / 稳定度储备 /
积分中的任何一个出现正向增长，D3 与 D4 连环扣分。
与此对称，静止是有代价的：悬停在齿位边缘而不锚定，稳定性储备按每秒约 5% 持续流失；
唯一能回补稳定度的窗口是「锁定同调驻留」。能量的唯一来源是不对称功（见第 2 层
（一）3），匀速顺流滑行不产生任何回补。

地雷三　反常识风阻与下沉反冲力学
顺风不加速——顺风时阻尼被非线性放大到约 1.40 倍，同角度、同推力向下推演同一时长，
顺流侧的末速绝对值必须低于逆流侧，顺流侧的速度损失必须显著大于逆流侧；
逆风迎角产生升力，逆风的抛物线顶点更高、滞空更久。
下沉冲量不是常量，它与冲击速度的平方正相关：v_sink = 1.2 × (1 + v_impact² / 200)。
离开齿面的瞬间梭子被反方向弹起，恢复系数 k = 0.68；被弹起的齿位同时点燃一段
500 ms 的引信，引信到期后碎裂为不可站立的虚空，虚空期满后由固定种子重组。

另外三条次级回路同样必须可逐帧观测：
　· 逆向不逆转熵——反转滚动轴时齿轮反转，但磨损累积与尘粒扩散的方向不随之反转；
　· 周期锁定——各级轮系周期的最小公倍数锁死在一个宏周期上，不可能更早复位；
　· 失败留痕——回溯不会把账本清零，重试期间的增益按逆向倍率结算，磨损照旧累积。

第 5 层　视觉要求、确定性接口与技术边界
────────────────────────────────────────────────────────────

视觉要求（跨帧不得漂移）：
　· 主色固定为暗底铜金：近黑的暖底、铜金刻线；宝石红一类只用于警告与回溯，
　　 同调态用青绿一类；
　· 刻度环上必须出现「子丑寅卯辰巳午未申酉戌亥」十二个字，字面顺序即主承力齿的
　　 排布顺序，十二个字始终水平排布在环外；
　· 全部数值等宽对齐，量纲与单位在仪表上显式标注；
　· 只允许系统等宽字体栈，禁止外部字体；
　· 各画布的角标标题固定为「A · 主视窗 十二时辰刻度环」「C · 传动比账本与相位图」
　　 「D · 齿位寿命环与实时损耗率」「E · 对流矢量罗盘与时段」与「状态断面」，
　　 跨帧一致；
　· 底部控制条必须包含一条进度条、四个可切换开关（自动走时 / 闭环 / 时间微距 /
　　 质检叠层）与一段实时读数（相位、物理相位、世界时刻、帧号）。开关切换后自身
　　 必须高亮；自动走时与时间微距必须真实改变指令相位的推进方式，闭环必须在结算
　　 之后自动重开一局，质检叠层则把判据读数叠加到主视窗上。

必须提供挂在全局的确定性接口对象：
　· 生命周期：开局 / 重开 / 退回待机 / 设定工况；
　· 时间轴：设定滚动位置（指令相位）、单步微调、连续走时到某位置；
　· 推演：按定长步进推进若干帧、冻结、解冻、强制全量重绘；
　· 读数：当前状态名、完整遥测快照、常量契约快照、分层转角快照、轮系啮合与齿数比
　　 误差快照、状态机决策表快照、账本快照；
　· 布场：直接设定操纵面、锚定开关、手操开关、制动开关、速度与高度、势能 / 稳定度 /
　　 疲劳 / 磨损 / 连击 / 蓄能，以及把梭子瞬移到指定齿位；
　· 手势入口：跃迁、下压、蓄力开关、释放、相位翻转、悬索抓取与释放、同调脉冲、
　　 涡旋生成、涡旋清空；
　· 强制触发：越限、撞击外缘、显式收束。

采集契约：冻结之后所有派生量只读，重复执行同一驱动脚本必须得到逐位一致的结果。
常量契约必须把题面中出现的每一个判据阈值以命名常量的形式暴露，运行期只读。

绝对禁止：
　· 任何外部依赖、CDN、外部字体、外部图片、图标库、动画库；
　· 内嵌位图、Base64 贴图、用画布截图冒充程序化绘制；
　· 框架标签、内联框架、外部脚本引用、样式表引用、导入规则、资源地址规则；
　· 真随机数发生器、系统当前时间、由挂钟推进的定时器——一切派生量必须由滚动位置
　　 与定长步进确定性展开；
　· 用纯匀速旋转或关键帧轮播冒充机械：机审会以 60 帧逐帧抓取角速度的一阶与二阶
　　 导数，若整个周期内角加速度的变化率恒等于零，直接判定匀速静态作弊；逐图切换
　　 或关键帧轮播冒充连续动画重建同样直接判负；
　· 写死的角速度常数、写死的传动比、写死的驻留时长、写死的结算数字；
　· 点击一下直接跳到结算，或用一个全局绘制函数顺序重画全部画布冒充多画布；
　· 控制台出现任何未捕获异常或错误输出。

硬性验收指标：
　· 1280×720 启动成功，首帧既非纯白也非纯黑；
　· 六块画布物理独立，位图尺寸与像素内容互不相同；
　· 相位走满 1.000000000 时结算，结算分数可由账本重放复算并落在 [0, 100]，
　　 各项权重之和归一化为 1.000；
　· 单文件纯文本体积不低于 70 KB；
　· 60 秒连续运行无未捕获异常、无持续劣化；
　· 1024 至 2560 视口宽度下均无横向溢出。

最终产物必须是一个 HTML（.html）单文件，样式与脚本全部内联。
