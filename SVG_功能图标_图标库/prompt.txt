矢量与结构要求：主画布 viewBox="0 0 1536 864"，图标网格置于 translate(168,32) 的子坐标系内；每枚图标由圆角矩形卡片（tile）+ 居中图标分组 + 底部名称文字构成，图标内部用 Path、Circle、Rect 组合绘制，描边细节用圆形线帽（stroke-linecap round）；配色集中用 CSS 变量定义（--ic 主色、--ic2 辅色、--panel 卡片、--line 描边等），切换配色仅改变量；图层遮挡顺序为背景 → 蓝图网格 → 图标卡片 → 编号徽标 → 图例。真矢量实现：禁止 <image>、Base64 位图、Canvas 截图或 CSS 背景冒充，全部用 Path、Circle、Ellipse、Rect 与渐变/变量绘制。

交互：顶部 6 个标签按钮（整体/配色/特写/线稿/标注/选中）点击切换视图；特写为对图标分组做 translate+scale 的镜头推近；线稿切换为描边蓝图样式；标注显示编号徽标与图例；选中切换为首页卡片反白、其余置灰。悬停任一图标时该卡片浮起投影并高亮描边，同时显示其名称。

实现要求：单个 HTML 文件，CSS 与 JS 全部内联，字体用系统字体，无任何外部图片/字体/脚本/CDN 依赖，禁止 iframe/srcdoc，完全离线可运行；SVG viewBox 有效、可无损缩放，双击打开即可正常显示，持续运行无未捕获错误。

最终产物必须是一个 HTML（.html）文件，CSS 与 JS 全部内联，双击即可打开运行。
