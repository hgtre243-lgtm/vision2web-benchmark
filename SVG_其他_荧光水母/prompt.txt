主体部件（全部用 SVG 基本图形与 Path 绘制，共 9 个部件）：
① 伞盖——青色到紫蓝的半透明渐变半球形伞体，顶部带径向高光；
② 辐射管——从伞顶中心向伞缘放射的细管纹路（多条直线 Path）；
③ 器官瓣——伞内中央四瓣十字排布的洋红发光器官；
④ 伞缘褶边——伞底一圈波浪起伏的下垂褶边；
⑤ 伞缘发光点——褶边下缘与伞缘成排的亮青发光点（带光晕）；
⑥ 胃囊——伞底中央一枚短小的花边胃囊；
⑦ 口腕——胃囊下方四条下垂飘动的褶皱腕带；
⑧ 触须——伞缘下 12 根细长下垂的波浪触须；
⑨ 触须发光节——各触须中段与末端的发光节点（带光晕）。

矢量与结构要求：主画布 viewBox="0 0 1536 864"，水母主体置于 translate(168,32) 的子坐标系内；伞盖轮廓为单条闭合平滑 Path，顶部高光与内部器官用 clip-path 裁剪到伞盖轮廓内（蒙版裁剪）；填充用线性/径向渐变（伞盖上下渐变、器官径向、发光点径向光晕、背景径向），触须为描边曲线；图层遮挡顺序为背景 → 光晕/微粒/气泡 → 触须 → 胃囊/口腕 → 发光节 → 伞盖 → 辐射管/器官 → 褶边 → 发光点 → 标注。真矢量实现：禁止 <image>、Base64 位图、Canvas 截图或 CSS 背景冒充，全部用 Path、Circle、Ellipse、Rect 与渐变/裁剪绘制。

交互：顶部 6 个标签按钮（整体/配色/头部/尾部/线稿/标注）点击切换视图；头部/尾部为对水母分组做 translate+scale 的镜头推近；线稿切换为描边蓝图样式；标注显示编号与图例。悬停任一部件时该部件提亮发光并显示其名称。

实现要求：单个 HTML 文件，CSS 与 JS 全部内联，字体用系统字体，无任何外部图片/字体/脚本/CDN 依赖，禁止 iframe/srcdoc，完全离线可运行；SVG viewBox 有效、可无损缩放，双击打开即可正常显示，持续运行无未捕获错误。

最终产物必须是一个 HTML（.html）文件，CSS 与 JS 全部内联，双击即可打开运行。
